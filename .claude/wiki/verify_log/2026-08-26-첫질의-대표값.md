# 첫 질의 비용의 대표값과 화면 왕복 — 45.1초는 재현되지 않는다

- 검증일: 2026-08-26
- 대상: `plan_log/검색-생성.md` 「다음 승인 단위」의 **A**(첫 질의 대표값)·**B**(화면 체감). 리랭커가 켜진 `ad1bf8d` 위에서 쟀고 **제품 소스는 안 고쳤다**
- 비용: 생성 LLM(`gpt-4.1-mini`) **2회** (사용자 승인) · vision **0회** · llamaparse **0회** · 임베딩 API **0회**

## 1. 확인하려 한 것

임계값이 아니라 **대표값**이다. 6회차가 첫 질의를 `11.9~45.1초` 범위로 남기면서
*"운영 uvicorn 은 45초 쪽에 가깝다"* 는 가설을 달아 뒀다. 그 가설이 참이면 *기동 시 미리
적재할지* 가 설계 결정이 되고 `local_ce.py` 의 게으름 계약과 정면으로 걸린다.

그래서 둘을 잰다 — (A) **운영 배선 그대로의** 첫 질의 비용과 그 분해, (B) 사용자가 실제로
무는 왕복(생성 포함). A 는 무료라 먼저 하고, B 는 생성 과금이라 승인 뒤에 했다.

## 2. 가상 데이터

**대표값 자체는 합성으로 못 잰다** — 재려는 값이 모델 가중치의 디스크→RAM 적재 시간이라
합성 입력이 만들 수 있는 것이 아니다. 합성으로 만든 축은 하나다: **캐시 무력화**.

질의 문자열 뒤에 nonce 를 붙여 임베딩 캐시와 리랭크 캐시를 **둘 다** 미스로 만든다.

```python
NONCE = sys.argv[2] if len(sys.argv) > 2 else str(time.time_ns())
embedder.embed_query(f"워밍업 {NONCE}")
retrieve(f"기관이 이관 전에 확인할 사항은 무엇인가 {NONCE}", ...)
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| nonce 없음 (앞 실행이 캐시를 채운 뒤) | 캐시 적중 → 적재가 안 보인다 | `embedder_first_encode` 0.001 · `reranker_first_query` 0.005 · `cache_hits` 2 · `reranked` **0** | 의도한 변화 — 캐시가 측정을 통째로 삼킨다 |
| nonce 있음 | 전부 미스 → 적재가 보인다 | `embedder_first_encode` 12.556 · `reranker_first_query` 9.824 · `cache_hits` 0 · `reranked` **100** | 의도한 변화 |

**이 칸이 없었으면 "첫 질의는 0.005초"로 적을 뻔했다.** 인계 문서의 함정 2(*"효과 없음"과
"안 돌았음"이 안 갈린다*)와 같은 종류이고, 갈라 준 것은 `reranked` 가 0 이라는 사실이다.

### 곁다리 — 공허한 확인 하나를 만들었다가 잡았다

첫 스크립트가 `getattr(usage, "warnings", [])` 로 경고를 읽어 `[]` 를 찍었다. 그런데
`RerankUsage` 에는 `warnings` 필드가 **없다** — 기본값 `[]` 를 읽고 "경고 없음"으로
착각한 것이다. 실제 자리는 리랭커 객체의 `reranker.warnings` 다(`run_eval.py` 가 그렇게 읽는다).
`getattr` 기본값으로 계약을 확인하면 **없는 필드가 통과로 보인다.**

## 7. 재지 못한 것

- **생성 품질** — 골든 답변이 없다. 2/2 가 `찾지 못했습니다` 인 것은 관찰이지 지표가 아니다
- **진짜 콜드 부팅** — OS 파일 캐시가 데워진 상태에서 쟀다. 재부팅 직후 첫 질의는 13초·6.3초
  둘 다 더 클 수 있다. **위 21.8초는 하한에 가깝다**
- **질의 표본** — A 는 nonce 질의, B 는 2건뿐이다. 질의 길이·후보 자수에 따른 분산을 안 쟀다

  0.09초라 청크 수 영향은 작을 것으로 보이지만 **재지 않았다**
- **`latency.py` 자체로 45.1초 재현** — 선적재 60질의로 조건을 흉내냈을 뿐, 그 스크립트를

- **미리 적재의 실제 효과** — 배경 스레드로 밀었을 때 기동이 얼마나 늦는지는 안 쟀다
