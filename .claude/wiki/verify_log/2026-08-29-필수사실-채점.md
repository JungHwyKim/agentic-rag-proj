# 필수 사실 채점의 첫 수 — 인용 정합성이 포화인 두 판에서 값 축이 갈린다

- 검증일: 2026-08-29
- 대상: [task_log/2026-08-29-필수사실-채점.md](../task_log/2026-08-29-필수사실-채점.md)
  (`plan_log/평가-세트.md` 13~15회차가 설계·라벨한 자[尺]의 채점 코드)
- 비용: **외부 API 호출 없음.** 생성·판정·리랭킹·임베딩 전부 0 — 소급(`--backfill`)이
  저장된 답변 원문과 그 실행의 컬렉션만 읽는다

## 1. 확인하려 한 것

**"규칙이 도는가" 와 "이 자[尺]가 갈리나" 둘이다.** 임계값을 정하는 회차가 아니다.

15회차가 `must_absent` 를 «채점 코드와 함께» 로 미루면서 *«채점이 `must_values`/
`must_points` 를 어떻게 쓰나»* 를 길목으로 남겼다. 그래서 물은 것은 셋이다.

1. **라벨 없는 행이 `0` 이 아니라 `None` 으로 나오나** — `0` 은 «다 틀렸다» 라는 다른 뜻이다
2. **값 축이 조건 사이에서 갈리나** — 안 갈리면 ② 지지 판정처럼 포화라 붙일 값이 없다
3. **어휘 겹침이 `must_points` 를 재는 데 쓸 만한가** — 유료 판정을 붙이기 전에 무료로 본다

## 2. 가상 데이터

무엇을 고립시켰나: **답변 한 줄과 라벨 한 줄만 두고 갈리는 축을 하나씩 남겼다.**
실제 리포트로는 이 대조가 안 된다 — 답변마다 표기·길이·근거가 함께 다르다.

```python
from evaluation.answer_eval import AnswerRow, score_must
from evaluation.qa_set import QAItem

def probe(answer: str, **labels) -> tuple[int | None, int | None]:
    row = AnswerRow(query_id="q1", query="질문", source_doc="안내서",
                    answerable=True, answer=answer)
    score_must(row, QAItem(query_id="q1", query="질문", source_doc="안내서",
                           gold_spans=["어떤 정답"], **labels))
    return row.must_values_hit, row.must_values_total

probe("아무 답")                                              # 라벨 없음
probe("제3조제12호에 따른", must_values=["제3조제12호", "별표1"])
probe("2020년 10월 1일부터 적용", must_values=["2020.10.1."])
probe("전체 중학교 206개가 대상", must_values=["206개교"])
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| 라벨 없음 | 네 칸 `None` | `None` | 통과 |
| 값 둘 중 하나만 답변에 | `(1, 2)` | `(1, 2)` | 통과 |
| **`2020.10.1.` ↔ `2020년 10월 1일`** | `(1, 1)` | `(1, 1)` | 통과 — 정규화가 먹는다 |
| **`206개교` ↔ `206개`** | `(0, 1)` | `(0, 1)` | 통과 — **일부러 안 맞춘다** |
| `학교장은` ↔ `학교장이` | 토막이 물린다 | `hit >= 2` | 통과 — 조사를 벗긴다 |
| 라벨이 하나도 없는 요약 | `must` 블록이 `None` | `None` | 통과 |
| 근거에 정답이 없는 행 | 조건부 분모에서 빠진다 | `1.0` vs 전체 `0.5` | 통과 |

## 3. 실제 데이터

입력은 **저장된 답변 리포트 둘**이다(사람 세트를 쓴 판이 이 둘뿐이다).
`--write` 뒤의 신원이다.

| 리포트 | bytes | sha256(12) |
|---|---:|---|
| `h-cohere-18w3-answers-mini-pdf.json` | 76,892 | `4c43e8dd2a07` |
| `combo-fuse-cohere-answers-qa_set_human-mini-cohere-off-luna-k5-pdf.json` | 75,018 | `7737c858c320` |

### 3-1. 첫 수 — 인용 정합성은 포화인데 값 축은 갈린다

| 생성 | 인용 정합성 | 최대 대비 | **값 재현** | 어휘 겹침 | 어휘 겹침(근거 조건부) |
|---|---:|---:|---:|---:|---:|
| `prod`(mini) | 0.472 | **1.000** | **5/6 = 0.833** | 0.553 | 0.603 |
| `luna` | 0.429 | **1.000** | **4/6 = 0.667** | 0.578 | 0.625 |

- **최대 대비가 두 판 다 1.000 이다** — 인용 축은 이 짝에서 아무것도 안 가른다
- **값 축은 1건 갈린다** — `제3조제12호` 를 `mini` 는 인용하고 `luna` 는 안 한다
- **분모가 6이라 어느 수도 인용하면 안 된다**(한 건이 16.7%p). 읽을 수 있는 것은 **방향**뿐이다
- 어휘 겹침은 조건부로 올라간다(0.553→0.603 · 0.578→0.625) — 근거에 정답이 온 행이
  더 높다는 뜻이라 **조건부 칸을 만든 전제와 부호가 맞는다.** 다만 차이가 작다

### 3-2. 날짜 정규화가 없었을 때 — 놓친 값 셋 중 **둘이 거짓 음성**

정규화를 넣기 **전** 실측이 `4/6`·`3/6` 이었고, 놓친 값을 하나씩 읽었다.

| 값 | mini | luna | 읽어 보니 |
|---|---|---|---|
| `2020.10.1.` | X | X | **둘 다 거짓 음성** — 답변이 `2020년 10월 1일` 로 정확히 말한다 |
| `별표1` | X | X | 진짜 누락 — 두 답변 다 별표를 아예 안 언급한다 |
| `제3조제12호` | O | X | **진짜 차이** |

정규화를 넣으니 **각각 +1**(`4/6→5/6` · `3/6→4/6`)이고 **차이 1건은 그대로 남는다.**
즉 표기 문제가 두 판을 똑같이 깎고 있었다 — 차이는 살아남지만 절대값은 못 썼다.

### 3-3. 소급이 옛 칸을 안 건드렸다

| 항목 | 기준(소급 전) | 이번 | 판정 |
|---|---|---|---|
| 인용 네 칸 재계산 일치 | — | **30/30 · 27/27** | 자기 검증 통과 |
| 옛 요약 칸 이동 | 0 | **0** | 불변 |
| `negative.must` | — | **`None`** | 설계대로 — 부정 25건에 라벨이 없다 |
| 행 `must_*` 저장 | 없음 | **43행 전부** | 아래 5절 참고 |

## 5. 판정

| 항목 | 판정 | 근거 |

## 7. 재지 못한 것

- **`must_points` 를 LLM 이 어떻게 채점할지 안 쟀다.** 이 회차는 어휘 탐침까지다 —
  **어휘 겹침은 상한도 하한도 아니다**(낱말이 다 있어도 뜻이 다를 수 있고, 바꿔 쓴 답변은
  낱말이 없어도 사실을 담는다). 판정과 견주려면 유료 실행이 필요하다
- **행 `must_*` 를 저장하는 것이 테스트로 안 막혀 있다.** 처음 `--write` 는 요약만 싣고
  행을 빼서, **요약의 근거가 파일에 없는 상태**를 만들었다(재소급하면 같은 수가 나오지만
  저장된 행으로 다시 요약하면 `None` 이다). 고쳤고 실측으로 43행 전부 실린 것을 확인했지만,
  **회귀 테스트는 못 붙였다** — 백필 경로가 qdrant 컬렉션을 요구해 단위 테스트로 못 세운다
- **`qa_set.jsonl` 60건 판 다섯은 소급 안 했다** — 그쪽은 `must_*` 라벨이 없어
  `must` 가 `None` 으로만 실린다. 실익이 없어 안 건드렸다
- **표본** — 값 축의 분모가 **6**이고 라벨 18건 중 값이 있는 것은 4건이다.
  `qa_set.jsonl`(값 밀도 50%)로 넓히면 분모가 커지는데 그쪽은 골든 라벨이 없다
- **어휘 겹침의 조사 목록**은 이 세트를 보고 열거한 것이라 다른 코퍼스에서 안 맞을 수 있다.
  어미 활용(`지정해야` ↔ `지정한다`)은 아예 안 다룬다
