# gpt-5.6-luna 파라미터 탐침 — 우리 판정 호출이 400 으로 죽는 자리 둘

- 검증일: 2026-08-27
- 대상: 모델 축(`gpt-4.1-mini` → `gpt-5.6-luna`) 비교를 **착수하기 전에** 호출 모양이 받는지만 본다.
  아직 어떤 프로필도 배선하지 않았고 코드도 안 고쳤다
- 비용: **`gpt-5.6-luna` 6호출 + `gpt-4.1-mini` 1호출 = 7호출.** 전부 100토큰 미만의 장난감
  프롬프트다. **86호출을 날리지 않으려고 먼저 쟀다**

## 1. 확인하려 한 것

사용자가 *"파라미터가 좀 달라서 공식 문서를 찾아봐야 할 것"* 이라고 짚었다. 문서를 먼저
봤는데 **집계 사이트마다 갈렸다** — 한쪽은 Chat Completions 스키마(`max_tokens`·
`reasoning_effort`·`response_format`)를, 다른 쪽은 Responses API 스키마(`max_output_tokens`·
`temperature` 0~2·`reasoning{}`)를 같은 모델의 것으로 보여준다. 그래서 **이 계정에서 실제로
무엇이 통과하는지**를 최소 호출로 확정했다.

물음은 하나다 — `OpenAIEvaluator._call_api()` 가 지금 보내는 네 인자
(`temperature` · `max_tokens` · `response_format` · `messages`)를 luna 가 받는가.

## 2. 가상 데이터

무엇을 고립시켰나: **인자 하나씩**이다. 실제 근거·질의 대신 장난감 프롬프트를 써서
*내용*이 아니라 *요청 모양*만 남겼다.

```python
# scratchpad/probe_luna.py — 저장소에 안 남긴다
MSGS = [
    {"role": "system", "content": '근거 충분성을 판정합니다. JSON 하나로만 답하세요: '
                                  '{"verdict": "sufficient" 또는 "insufficient", "reasoning": "한국어 한 문장"}'},
    {"role": "user", "content": "근거:\n\n[1] 유예기간은 공포 후 6개월이다.\n\n---\n\n"
                                "질문: 유예기간은 얼마인가요?\n\n이 근거로 위 질문에 답할 수 있습니까?"},
]
CASES = [
    ("지금 코드 그대로",        dict(temperature=0.0, max_tokens=512, response_format={"type": "json_object"})),
    ("temperature 빼고",        dict(max_completion_tokens=512, response_format={"type": "json_object"})),
    ("+ reasoning_effort=none", dict(max_completion_tokens=512, response_format={"type": "json_object"}, reasoning_effort="none")),
    ("예산 4096 · reasoning 기본", dict(max_completion_tokens=4096, response_format={"type": "json_object"})),
]
# 뒤이어 temperature 축만 따로 (max_tokens 가 먼저 걸려서 못 봤기 때문에)
#   ("temperature=0.0", dict(temperature=0.0, max_completion_tokens=64))
#   ("temperature=1.0", dict(temperature=1.0, max_completion_tokens=64))
# 그리고 gpt-4.1-mini 가 새 이름을 받는지
#   ("gpt-4.1-mini", dict(temperature=0.0, max_completion_tokens=64))
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| luna · 지금 코드 그대로 | 알 수 없음 | **400** `Unsupported parameter: 'max_tokens' is not supported with this model. Use 'max_completion_tokens' instead.` | 고쳐야 한다 |
| luna · `temperature` 빼고 `max_completion_tokens` | 통과 | **통과** · `finish_reason=stop` · JSON 정상 | 이 모양으로 간다 |
| luna · `+ reasoning_effort="none"` | 통과 | **통과** · 결과 동일 | 받기는 받는다 |
| luna · 예산 4096 · reasoning 기본 | 통과 | **통과** · 결과 동일 | 예산을 키울 이유가 없다 |
| luna · `temperature=0.0` | 알 수 없음 | **400** `Unsupported value: 'temperature' does not support 0.0 with this model. Only the default (1) value is supported.` | **안 보낸다** |
| luna · `temperature=1.0` | 통과 | **통과** | 기본값이라 보낼 이유가 없다 |
| **`gpt-4.1-mini` · `max_completion_tokens`** | 알 수 없음 | **통과** | **분기가 필요 없다** |

**`reasoning_tokens` 는 네 경우 모두 0 이었다**(`completion_tokens_details`). 이 프롬프트가
추론을 안 끌어냈다는 뜻이고, *예산을 추론이 먹어 빈 응답이 온다* 는 흔한 함정은 **여기서는
안 보였다.** 다만 실제 근거 5~10개를 실은 프롬프트에서도 그런지는 안 쟀다(7절).

## 3. 실제 데이터

**없음.** 실제 세트로는 한 건도 안 돌렸다 — 이 회차의 물음이 *요청 모양* 이라 장난감
프롬프트로 답이 난다. 세트를 태우는 것은 다음 세션이다(172호출).

## 4. 테스트 스위트

코드를 안 고쳤다. 직전 커밋(`d50b2da`)의 값이 그대로 유효하다 —
`ruff All checks passed!` · `pytest 1205 passed, 5 skipped, 7 deselected`.

## 5. 판정

- **의도한 변화 아님 — 착수 전 사실 확인이다.** 얻은 것은 셋이다.
  ① `max_tokens` → **`max_completion_tokens`** 로 바꿔야 하고, **`gpt-4.1-mini` 도 새 이름을
  받으므로 모델별 분기가 필요 없다.** ② `temperature` 는 luna 에서 **0 을 못 쓴다** — 보내지
  않는 것이 유일하게 깨끗한 답이다(1.0 을 보내는 것은 기본값을 명시하는 것뿐이다).
  ③ `response_format={"type":"json_object"}` 는 그대로 받는다
- **이 비교는 등가가 아니다 — 이것이 이 회차의 제일 중요한 결과다.**
  `EvaluatorConfig.evaluator_temperature = 0.0` 은 *"판정은 재현이 값어치라 0"* 이라는 이유로
  박은 값인데 **luna 에서는 그 값이 금지**다. 그래서 지금까지의 수치(v1·v2·v3, 전부
  `gpt-4.1-mini` · temperature 0)와 luna 수치 사이에는 **모델과 샘플링이 함께** 들어간다.
  세 판의 차이가 전부 한두 건 규모였던 것을 생각하면, **모델 간 절대 수치 비교로는 우열을
  못 말한다**
- **그래서 다음 세션의 설계가 B 로 정해졌다**(사용자 결정) — luna **안에서** v1·v3 를 둘 다
  재서 *"프롬프트 온도 효과가 모델을 타는가"* 를 본다. 등가 비교가 luna 내부에서 성립한다
- **딸린 사실**: luna 는 temperature 를 못 고정하므로 **같은 명령을 다시 돌리면 수가 달라질
  수 있다.** 지금까지 성립하던 *"캐시가 받아서 무료로 재현"* 이 luna 에서는 재현이 아니라
  **같은 응답을 되읽는 것**이다. 캐시를 지우고 다시 돌리면 다른 표가 나올 수 있다

## 7. 재지 못한 것

- **실제 근거를 실은 프롬프트에서 `reasoning_tokens` 가 0 인지 안 쟀다** — 장난감 프롬프트
  에서만 0 이었다. 근거 5~10개를 실으면 추론이 붙어 512 예산을 먹고 **빈 응답**이 올 수 있다.
  그러면 파서가 `None` 을 돌려 **43건이 전부 `verdict="failed"`** 가 되는데, 다행히 채점 도구가
  **실패 열**을 따로 세므로 표에서 바로 보인다. 다음 세션은 **1건 먼저 돌려 보고** 172호출로 간다
- **`reasoning_effort` 를 무엇으로 둘지 안 정했다** — 받기는 받는다는 것만 확인했다.
  기본(`medium`)과 `none` 이 판정 정확도를 가르는지는 **또 다른 축**이라 이번 비교에 섞지 않는다
- **생성(`GENERATION_MODEL`)·유료 리랭커는 안 봤다** — 같은 파라미터 제약을 받을 것이 거의
  확실하지만 재지 않았다. 그쪽을 luna 로 바꾸는 것은 별개 결정이다
- **가격은 문서값만 안다** — OpenRouter 기준 입력 $0.20/M · 출력 $1.20/M. 실제 청구는 안 봤다
