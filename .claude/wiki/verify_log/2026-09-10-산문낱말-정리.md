# 산문·낱말 정리 — 걷어낸 건수, 남긴 건수, 훅의 헛경보 표면

- 검증일: 2026-09-10
- 대상: [task_log/2026-09-10-산문낱말-정리.md](../task_log/2026-09-10-산문낱말-정리.md)
- 비용: 외부 API 호출 없음 (전수 조사와 문자열 치환뿐이다)

## 1. 확인하려 한 것

셋이다.

1. **얼마나 있나** — 걷어낼 낱말과 모호한 표 헤더가 어디에 몇 건인가. 범위를 정하는 재료다
2. **다 걷어냈나** — 고친 뒤 잔량이 «일부러 남긴 것» 뿐인가
3. **훅이 조용한가** — 새 검사가 헛경보를 얼마나 내는가. 상시가 되면 `SKIP_PROSECHECK=1` 이
   습관이 되어 검사가 통째로 죽는다

1·2 는 «건수가 맞는가» 이고 3 은 «임계값이 맞는가» 에 가깝다. 그래서 3 에만 대조군이 있다.

## 2. 가상 데이터

무엇을 고립시켰나: **훅의 세는 규칙**. 저장소 파일이 아니라 손으로 지은 문자열을 넣어,
«세야 하는 것»과 «안 세야 하는 것»을 한 축씩 갈랐다. 전문은
`tests/hooks/test_prose_style_check.py` 이고 아래는 판정을 가른 입력들이다.

```python
import sys
sys.path.insert(0, ".claude/hooks")
import prose_style_check as h

h.count("답변 품질을 재는 자[尺]가 없고, 같은 잣대다. 비[比]도 안 낸다.")
h.count("계단 세 판으로 다시 만들었고 HWPX 판은 0개다.")
h.count("그 뒤집힘은 완전 동점을 stable 정렬이 가른 것이다. 그 밀림이 남는다.")
h.count("| 항목 | 판정 |\n|---|---|\n| a | b |\n\n| | 값 |\n|---|---|\n")
h.count("낱말 `자[尺]`·`잣대`·`판` 은 쓰지 않는다. 대신 `기준`·`실행`·`버전` 을 쓴다.")
h.count('토큰 칸은 안 채운다 — 0 은 *"이 API 는 토큰으로 안 판다"* 이다.')
h.count("판정이 답변을 안 바꾼다. 판단도 마찬가지다. 이 문서들의 확장판이다. 초판은 8월이다.")
h.count("| 질의 | 판정 | 근거 |\n|---|---|---|\n| q1 | 통과 | — |\n")
h.count("그것을 개선으로 읽으면 틀린다.")
h.count("A 로 읽으면 틀린다. B 로 읽으면 틀린다. C 로 읽으면 틀린다.")
h.written_text({"old_string": "자[尺]가 없다", "new_string": "재는 방법이 없다"})
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| `자[尺]` + `잣대` + `비[比]` 한 문장 | 3 | 3 | 의도한 변화 |
| `세 판` + `HWPX 판` | 2 | 2 | 의도한 변화 |
| `그 뒤집힘은` + `그 밀림이` | 2 | 2 | 의도한 변화 |
| `\| 항목 \|` + 빈 첫 칸 | 2 | 2 | 의도한 변화 |
| 규칙 문구(「쓰지 않는다」) | 0 | 0 | 의도한 변화 |
| 동사 `안 판다` | 0 | 0 | 의도한 변화 |
| 복합어 `판정`·`판단`·`확장판`·`초판` | 0 | 0 | 의도한 변화 |
| 이름이 있는 첫 칸 `\| 질의 \|` | 0 | 0 | 의도한 변화 |
| 관용구 1회 | 0 | 0 | 의도한 변화 |
| 관용구 3회 | 2 (되풀이만) | 2 | 의도한 변화 |
| `Edit` 의 `old_string` | 안 센다 | 안 센다 | 의도한 변화 |

**복합어 갈래가 제일 시끄러울 자리였다** — `판정` 이 저장소 전체에 3,432건이라, 정규식이
그것을 물면 훅이 쓸모없어진다. 뒤 글자 제외 목록(`정|단|별|례|매|사|독|권|형|본|다`)과 앞 글자
제외 목록(`재오초조간심비공본장되`)이 그 자리를 막는다.

## 7. 재지 못한 것

- **열거 목록이 몇 개면 충분한가.** 명사화 주어 8개 · 관용구 7개는 실측에서 나온 씨앗이고,
  이것으로 충분한지는 안 쟀다. 재려면 훅을 켠 채 새 기록 몇 회차의 헛경보와 누락을 센다
- **기록 3폴더의 낱말이 새 기록으로 새는가.** `plan_log` 는 "앞 회차를 먼저 읽는다" 를
  요구해 구멍이 남아 있다. 훅이 새 기록에서 세는 건수를 회차별로 봐야 정해진다
- **소스 주석 문체가 실제로 지켜지는가.** 규칙을 `CLAUDE.md` 「코드 컨벤션」과 메모리에
  뒀는데, 그것이 먹는지는 다음 세션이 새로 쓴 주석을 읽어야 안다
- **`HANDOFF.md` 는 안 고쳤다.** 피어 세션이 만든 커밋 안 하는 포인터 파일이고
  (*"읽고 지운다"*), 계획의 파일 목록에도 없었다. `잣대` 1건이 남아 있다
- **실파일 파싱을 안 돌렸다.** 파서를 안 건드렸고 `tests/fixtures/` 도 이 환경에 없다.
  적재 회귀는 `regression/baseline.json` 을 안 건드린 것으로 갈음한다
