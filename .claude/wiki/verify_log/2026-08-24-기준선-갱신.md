# 회귀 기준선이 낡았는지 재고, tests 블록을 815 → 950 으로 갱신했다

- 검증일: 2026-08-24
- 대상: `regression/baseline.json` — 기준선 시점 `b3c6915` 이후 HEAD `8d742af` 까지의 커밋 일곱
- 비용: **외부 API 호출 없음** (`detect_regions()` 단독 · `-m integration` 미실행)

## 1. 확인하려 한 것

"기준선이 낡았는가" 하나다. **규칙이 도는가가 아니라 기준값이 맞는가**라
실파일과 실제 테스트 스위트로만 답할 수 있고 가상 데이터로는 답이 안 나온다.

부수로 하나 더 봤다 — `by_area` 의 *"수집 수는 환경 독립"* 이라는 2026-08-23 의 주장이
**새 테스트 파일 아홉이 들어온 뒤에도** 유지되는가. 그때 한 번 틀렸다가(`test_hwpx_real.py`
의 수집 시점 glob) 고친 자리라 회차마다 다시 볼 값어치가 있다.

## 2. 가상 데이터

없음 — 이 검증의 입력은 저장소의 테스트 스위트와 `tests/fixtures/` 실파일이라
한 축만 바꾼 합성 입력을 만들 자리가 없다.

대신 **환경 축을 한 축만 바꾼 대조군**을 만들었다. 코드는 HEAD 그대로 두고 환경만 비웠다 —
`git worktree` 로 떼어낸 트리에는 `tests/fixtures/` 도 `.env` 도 없다. 합성 *입력*이 아니라
합성 *환경*이라 이 절이 아니라 4절에 적는다.

```powershell
git worktree add <scratch>\head-check HEAD --detach
cd <scratch>\head-check
C:\agentic-rag-proj\.venv\Scripts\python.exe -m pytest -q
```
