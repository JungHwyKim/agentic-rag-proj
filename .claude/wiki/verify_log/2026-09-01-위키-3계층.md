  파일 하나로 옮겼다

**그리고 논증 하나가 반대로 뒤집혔다** — 회차 전반부에 *"CLAUDE.md 의 「문자≈토큰」은

**분할에서 한 번 더 틀렸고 검사가 못 잡았다.** `next-stages.md` 를 가를 때 README 구간을 3줄
