## 2. 가상 데이터

무엇을 고립시켰나: **실패를 일부러 일으키는 가짜 클라이언트**로 경고 경로만 남겼고,
`clear()` 는 `delete_collection` 을 기록하는 가짜로 호출 여부를 봤다.

```python
# tests/answer_cache/test_answer_cache.py — 상한을 넘겨 놓고 길이와 최근성을 함께 본다
def test_warnings_stop_growing_at_the_cap():
    class _Boom(_FakeClient):
        def query_points(self, **_): raise RuntimeError("저장소가 죽었다")
    cache = _cache(_FakeStore(_Boom()))
    for _ in range(qdrant_cache._MAX_WARNINGS + 50):
        cache.lookup("질문", embedder=_FakeEmbedder())
    assert len(cache.warnings) == qdrant_cache._MAX_WARNINGS

def test_warnings_keep_the_most_recent():
    cache = _cache(_FakeStore(_FakeClient()))
    for i in range(qdrant_cache._MAX_WARNINGS + 5):
        cache._warn(f"경고 {i}")
    assert cache.warnings[-1] == f"경고 {qdrant_cache._MAX_WARNINGS + 4}"
    assert "경고 0" not in cache.warnings
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| 실패 150회 (상한 100) | 길이가 100 에서 멈춤 | 100 | 통과 |
| 경고 105개 | 최신이 남고 `경고 0` 은 없음 | 그대로 | 통과 |
| `clear()` — 컬렉션 있음 | `delete_collection` 1회 + `True` | 그대로 | 통과 |
| `clear()` — 컬렉션 없음 | 만들지 않고 `True` | `created == []` | 통과 |
| 비운 뒤 조회 | 미스 | 미스 | 통과 |
| `delete_collection` 이 예외 | 안 던지고 `False` + 경고 | 그대로 | 통과 |
| 색인 라우트, 캐시 켜짐 | `clear()` 1회 · 객체는 그대로 | 그대로 | 통과 |
| 색인 라우트, 캐시 꺼짐(`None`) | 204, 아무 일 없음 | 204 | 통과 |
| 색인 **실패** | `clear()` 0회 | 0회 | 통과 |

**마지막 줄이 이번에 새로 잠근 계약이다** — 저장소가 안 바뀌었는데 비우면 헛되이 버린다.
`clear()` 를 `try/finally` 밖 성공 경로에 둔 것이 그것을 만든다.

### 패러프레이즈 쌍 80건 — 겹침 분포

`overlap_ratio(paraphrase, [base_query])`. **임베딩이 아니라 낱말 겹침이다** — 유사도가
아니라 *세트가 오염됐는지* 를 보는 값이다.

| 겹침 구간 | 쌍 수 |
|---|---:|
| 0 (완전히 다른 낱말) | 20 |
| 0 초과 ~ 0.10 | 12 |
| 0.10 ~ 0.20 | 37 |
| 0.20 ~ 0.30 | 5 |
| 0.30 이상 | 6 |

중앙값 **0.111** · 평균 0.117 · 최소 0.000 · 최대 0.462.

**대조군이 있어야 이 수가 말을 한다** — 기존 LLM 질의 세트는 겹침 0 구간이 60건 중 **8건**
뿐인데(`verify_log/2026-08-24-어휘겹침.md`), 이 세트는 80건 중 **32건이 0.10 이하**다.
의도한 방향이다.

검수 우선(겹침 0.30 이상) 6건 중 상위 다섯: `sch-12`(0.462) · `sch-09`(0.455) ·
`bas-08`(0.400) · `bas-11`(0.385) · `sch-08`(0.333). 전부 **짧은 질의**라 낱말을 더 바꾸면
뜻이 흔들리는 쪽이다 — 틀린 쌍이라는 뜻이 아니라 사람이 볼 자리라는 뜻이다.

## 7. 재지 못한 것

- **유사도 임계값** — 여전히 못 쟀다. 이번에 양성 쪽 재료(80쌍)를 만들었지만 **재려면
  임베딩이 필요하고 모델이 아직 안 정해졌다.** 그새 로컬 임베더(KURE-v1)가 붙어 갈래가
  둘이 됐으니, 어느 쪽으로 갈지 정해진 뒤에 잰다
- **쌍의 품질** — `reviewed_by: "pending"` 이다. 겹침 수치는 *낱말이 다른가* 만 말하고
  *뜻이 같은가* 는 말하지 않는다. 그건 사람만 판정한다
- **캐시가 켜진 상태의 색인 상호작용** — `clear()` 가 불리는 것까지는 쟀지만, 임계값이 없어
  **실제로 캐시가 채워진 채 색인이 도는 경로**는 못 쟀다. CORS 세션도 같은 것을 자기
  `verify_log` 에 남겼다
- **캐시 상한·퇴거** — 항목이 몇 개까지 느는지 여전히 안 쟀다. `clear()` 가 생겨 상한이 없어도
  색인마다 비워지지만, 색인이 드문 환경에서는 그대로 쌓인다
