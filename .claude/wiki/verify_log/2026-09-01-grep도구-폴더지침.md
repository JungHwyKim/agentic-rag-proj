## 1. 확인하려 한 것

둘이고 성질이 다르다.

    ① 임계값이 맞는가   「경로 없음 = 저장소 전체」 대우가 **얼마나 자주 발동하나**.
                        13회차가 이 미결을 미룬 유일한 근거가 그 빈도였다
    ② 규칙이 도는가     고친 뒤 `Grep` 이 실제로 지침을 싣고, 안 좁힌 호출은 침묵하는가

①이 이 판의 본체다 — **비율이 크면 「모든 폴더에서 조각 하나씩」을 설계해야 하고, 작으면
그 설계를 통째로 안 해도 된다.**

## 2. 가상 데이터

무엇을 고립시켰나: **`tool_input` 하나만** 바꾸고 저장소 트리·예산·조각 규칙을 고정했다.
훅을 서브프로세스로 돌려 배선까지 함께 본다(판정 함수가 맞아도 matcher 가 틀리면 소용없다).

```python
import json, subprocess
from pathlib import Path

ROOT = Path(r"C:\agentic-rag-proj")
PY, HOOK = ROOT / ".venv/Scripts/python.exe", ROOT / ".claude/hooks/folder_md_check.py"


def feed(sid, tool, tin):
    payload = {"hook_event_name": "PreToolUse", "tool_name": tool,
               "tool_input": tin, "session_id": sid}
    done = subprocess.run([str(PY), str(HOOK)], input=json.dumps(payload, ensure_ascii=False),
                          capture_output=True, encoding="utf-8", errors="replace", cwd=str(ROOT))
    out = (done.stdout or "").strip()
    return 0 if not out else len(
        json.loads(out)["hookSpecificOutput"]["additionalContext"])
```

## 3. 실제 데이터

입력은 문서가 아니라 **세션 전사**다 — `~/.claude/projects/C--agentic-rag-proj/*.jsonl`
**163개**에서 `Grep`·`Glob` 호출 **199건**을 뽑았다.

### 3-1. 분모를 먼저 갈랐다

| 갈래 | 처리 |
|---|---|
| 이번 세션(`0bb203a4…`) 13건 | **뺐다** — 이 판을 재려고 친 탐침이라 오염이다 |
| 서브에이전트 | **못 갈랐다** — `isSidechain` 키가 163파일에 다 있는데 **참인 줄이 0**이다 |
| 남은 분모 | `Grep` **148건** · `Glob` **38건** |

### 3-2. `Grep` 148건 — 「경로 없음」은 의도로 세야 한다

| 갈래 | 건수 | 비율 |
|---|---:|---:|
| `path` 를 안 줌 | 8 | 5.4% |
| `path` 가 저장소 뿌리 | 21 | 14.2% |
| **«폴더를 안 좁힘» 합계** | **29** | **19.6%** |
| 폴더를 좁힘 | 119 | 80.4% |

좁힌 119건 중 **폴더 지침을 여는 것 52건(43.7%)** → **호출 하나가 지침을 실을 확률 35.1%**
(52/148). 고치기 전에는 그것이 **전부 0**이었다.

**키 유무로만 세면 5.4%, 의도로 세면 19.6%다** — `path=<저장소 뿌리>` 21건은 키가 있어도
훅 입장에서 «안 좁혔다» 이고, 바로 그 새 결정을 발동시킨다.

### 3-3. `Glob` 38건 — 축이 다르다

| 갈래 | 건수 | 비율 |
|---|---:|---:|
| `path` 를 안 줌 | 27 | 71.1% |
| `path` 가 저장소 뿌리 | 8 | 21.1% |
| 폴더를 좁힘 | 3 | 7.9% |

`path` 로 보면 92.1%가 «안 좁힘» 인데, **폴더 신호가 `pattern` 에 산다** — 앞머리에 폴더가
있는 것 **27건(71.1%)**, 그중 지침을 여는 것 **8건**. `Grep`(52건)의 **6분의 1**이다.

### 3-4. 한 번 나온 그럴듯한 0

첫 판정 함수가 **`0/140`** 을 냈다 — *"경로를 줘도 지침을 여는 일이 한 번도 없다"* 로 읽으면
이 미결이 통째로 잘못 닫히는 수다. **원인은 실사용 경로가 절대 경로**(`C:\agentic-rag-proj\tests`)
인데 저장소 상대 경로와 비교한 것이었다. 고치니 **52/140**.
