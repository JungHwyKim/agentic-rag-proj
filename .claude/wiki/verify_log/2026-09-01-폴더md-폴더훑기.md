## 1. 확인하려 한 것

가설 셋이고 성격이 다르다.

    ① 규칙이 도는가   폴더를 훑는 명령에 지침이 실리는가 (넓히기 전 0자였다)
    ② 임계값이 맞는가  «디렉터리를 무엇으로 인정하나» 를 무엇으로 가르나
    ③ 회귀가 없나     기존 계약(이어싣기·중복 방지·침묵)이 그대로인가

②가 이 판의 진짜 질문이다 — 넓히는 방향이 하나가 아니고, **순진한 쪽은 실려야 할 폴더를
밀어낸다.**

## 2. 가상 데이터

무엇을 고립시켰나: **명령 문자열 하나만** 바꾸고 저장소 트리·훅 예산·조각 규칙을 전부 고정
했다. 훅을 서브프로세스로 직접 먹여 하네스를 안 거친다(세션 id 를 회차마다 갈라 마커를 피한다).

```python
# 명령 → 실린 자. 회차마다 세션 id 가 달라 마커가 안 걸린다
import json, subprocess
from pathlib import Path

ROOT = Path(r"C:\agentic-rag-proj")
PY, HOOK = ROOT / ".venv/Scripts/python.exe", ROOT / ".claude/hooks/folder_md_check.py"


def feed(i, command, tool="Bash", tin=None):
    payload = {
        "hook_event_name": "PreToolUse",
        "tool_name": tool,
        "tool_input": tin if tin is not None else {"command": command},
        "session_id": f"probe-{i}",
    }
    done = subprocess.run(
        [str(PY), str(HOOK)], input=json.dumps(payload, ensure_ascii=False),
        capture_output=True, encoding="utf-8", errors="replace", cwd=str(ROOT),
    )
    out = (done.stdout or "").strip()
    return 0 if not out else len(
        json.loads(out)["hookSpecificOutput"]["additionalContext"]
    )
```

합계는 이렇다.

| 규칙 | 누락 | 오탐 |
|---|---:|---:|

**「말아야」 두 줄의 1은 오탐이 아니다 — 이름으로 확인했다.** 그 명령들은 `backend/app` 을
실제로 무므로 `backend/CLAUDE.md` 가 오는 것이 정답이고, 걸러진 것은 검색어 쪽이다.

    grep -rn "cost" backend/app        맨낱말 → ['cost/CLAUDE.md', 'backend/CLAUDE.md']
                                       +구분자 → ['backend/CLAUDE.md']
    grep -rn "evaluation" backend/…    맨낱말 → ['evaluation/CLAUDE.md', 'backend/CLAUDE.md']
                                       +구분자 → ['backend/CLAUDE.md']

### 2-3. 부딪히면 조용히 틀리는 것이 아니라 **밀어낸다**

한 호출에 드는 조각이 사실상 하나라(3절), 부딪힌 폴더가 먼저 오면 일하는 폴더가 예산 밖으로
밀린다. 같은 명령을 규칙만 바꿔 `compose()` 에 태웠다.

    $ grep -rn "cost" backend/app
      맨낱말 허용   실린 자 2,286  →  cost/CLAUDE.md 만.  backend 는 한 줄도 안 온다
      +구분자 요구  실린 자 8,317  →  backend/CLAUDE.md (1/2)

`compose()` 가 얕은 폴더부터 채우는데 `cost`·`backend` 는 **깊이가 같아**(둘 다 2 parts) 명령의
토큰 순서가 이기고, `grep` 은 검색어를 경로보다 먼저 쓴다.

아니라 예산을 재게 된다.

## 3. 실제 데이터

입력은 픽스처가 아니라 **저장소에 커밋된 폴더 지침 일곱**이다(git 이 신원을 갖는다).

| 지침 | 자 | 조각 | 조각 1 |
|---|---:|---:|---:|
| `backend/CLAUDE.md` | 11,401 | 2 | 8,130 |
| `cost/CLAUDE.md` | 2,137 | 1 | 2,137 |
| `evaluation/CLAUDE.md` | 20,121 | 3 | 9,047 |
| `tests/CLAUDE.md` | 4,993 | 1 | 4,993 |
| `rag_pipeline/ingestion/CLAUDE.md` | 2,262 | 1 | 2,262 |
| `rag_pipeline/retrieval/CLAUDE.md` | 1,755 | 1 | 1,755 |
| `rag_pipeline/ingestion/loader/CLAUDE.md` | 12,522 | 2 | 8,998 |

**「한 호출에 조각 하나」의 근거가 이 표다** — 예산이 9,500인데 큰 셋의 조각 1이 8,130 ·
9,047 · 8,998 이라 둘째가 들어갈 자리가 없다. 작은 것끼리는 둘이 들어간다.

**살아 있는 관측 하나** — 이 판을 검증하며 친 `pytest tests/hooks` 가 `tests` 를 디렉터리로
물어 `tests/CLAUDE.md`(4,993자)를 통째로 실었다. **고치기 전에는 0자였던 자리다.**

**«구분자가 부딪힘을 실제로 가른다»** 까지다.

## 7. 재지 못한 것

- **판별자의 진짜 오탐률** — 11개는 모델이 고른 명령이다. 전사에 실제로 친 Bash 명령을
  분모로 삼아야 «얼마나 자주 놓치고 얼마나 자주 넘치나» 가 나온다
- **`ls backend` 꼴이 실사용에서 얼마나 흔한가** — 감수한 누락의 크기를 안 쟀다
- **`Grep` 도구의 「경로 없음」 비율** — B 안의 비용을 가늠할 재료인데 안 셌다
- **`load_reason == "compact"`** — 이 판에서도 못 봤다(12회차 미결 그대로)
- **셸 출력 채널의 정확한 상한** — 23,197 통과 · 37,141 잘림까지만(12회차 그대로)
