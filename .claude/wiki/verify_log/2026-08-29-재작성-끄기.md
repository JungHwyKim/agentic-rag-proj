- 검증일: 2026-08-29
- 대상: `plan_log/검색-생성.md` 48회차 · `.env` 한 줄(`REWRITE_MODEL` 값 비움) · **코드 변경 0**
- 짝: `verify_log/2026-08-29-리랭커-점수분포.md`(끄기로 한 근거인 기전)
- 비용: **유료 1질의분** — 생성 1 · Cohere 리랭킹 1 · 판정 1. 사용자 승인 받음.
  `-m integration` 미실행

## 1. 확인하려 한 것

코드가 안 바뀌었으므로 단위 테스트가 이 결정을 못 잰다. 물음은 **«실제로 꺼졌는가»** 하나다.

## 2. 가상 데이터

**없다.** 재는 것이 «이 머신의 `.env` 가 실사용 경로에 닿는가» 라, 합성이 답할 수 있는
질문이 아니다. 반대로 설정 갈래 자체는 `tests/retrieval` 이 이미 잠그고 있다.

## 3. 실제 데이터

### 3-1. 무료로 답해지는 넷 (질의를 보내기 전에)

| 확인 | 값 |
|---|---|
| `RewriteConfig()` 가 실 `.env` 를 읽은 값 | `rewrite_model=''` · `rewrite_mode='fuse'`(죽은 값) |
| `get_rewriter()` | **`None`** |
| 스위치가 실사용 경로에 닿나 | `routes/query.py` 가 질의마다 `get_rewriter(cfg.rewrite)` 를 부른다 |
| 답변 캐시 지문 | `rewriter_on=False` 에서 조각이 **`rewrite=off`** 로 갈린다(기존 항목은 안 지워지고 조회 때 미스) |
| 평가가 흔들리나 | **안 흔들린다** — `eval_config(rewrite="off"/"fuse")` 가 여전히 `None` / `gpt-4.1-mini` |

마지막 줄이 이 절의 요점이다 — *«평가 러너는 `.env` 를 이긴다»* 가 **이 변경에서도 성립하는
것을 실제로 찍었다.** 안 찍었으면 지난 수치들의 재현성이 추론으로 남는다.

### 3-2. 실사용 왕복 1회

서버는 **하나만** 띄웠다(`--reload` 없음). 8000 리슨 PID 를 두 번 불러 **5164 로 동일** —
Windows 의 중복 바인딩(2026-08-27 함정)을 배제했다.

| 항목 | 기준선 → 관측 |
|---|---|
| HTTP | **200** · 응답 10,654자 |
| 왕복 | **10,832ms** |
| `.cache/rewrite` | **390 → 390 (안 늘었다)** |
| `data/queries.jsonl` | 62 → 63줄 |
| 그 줄의 `source` | **`e2e`**(실사용 통계에 안 섞였다) |
| 그 줄의 `rewritten` · `rewrite_mode` | **둘 다 `null`** |
| 그 줄의 `cached` | `false` — 캐시 히트가 아니라 **진짜 미스**라 유료 경로가 돌았다 |
| 화면의 재작성 문구 3종 | *"…로 바꿔 검색"* · *"…도 함께 검색"* · *"재작성"* **전부 없음** |
| 왕복 문구 | 보낸 질문과 **글자까지 일치**(cp949 오염 배제) |

**`.cache/rewrite` 가 안 는 것이 껐다는 것의 유일한 물증이다** — 화면과 로그는 *«안 실렸다»*
까지만 말하지 *«안 불렀다»* 는 말하지 못한다.

`cached=false` 가 함께 붙은 것이 두 번째로 중요하다. 캐시가 히트했으면 검색 자체를 건너뛰어
**재작성이 꺼졌는지와 무관하게** 위 셋이 전부 같은 모양으로 나온다 — 그러면 이 회차가
아무것도 안 잰 것이 된다.

## 4. 테스트 스위트

코드 변경이 0이라 스위트를 이 회차에 귀속하지 않는다. 다만 `.env` 를 고친 직후 훅이
`tests/evaluation/test_verdicts.py` **2건 실패**를 물어왔는데 **내 것이 아니었다** —
피어가 `evaluation/verdicts.py` 에 재작성기를 배선하는 **중간 상태**였고, 몇 초 뒤 다시
돌리니 **16 passed** 다. `.env` 를 만진 직후라 *«내가 깼나»* 로 보이기 딱 좋은 자리였고
**가른 것은 다시 돌린 것 하나다.**

## 5. 판정

- **껐다 · 실사용 경로에서 확인됨.** 물증은 `.cache/rewrite` 불변이다
- **평가 재현성은 안 깨졌다**(3-1 마지막 줄)
- **왕복 10,832ms 를 기준선으로 쓰지 않는다** — 워밍업 직후 첫 질의이고 캐시 상태가
  제각각이다. 2026-08-27 이 같은 이유로 세 회차를 버렸다
- `verdict="insufficient"` 가 함께 나왔는데 **이 질의 하나의 관측**이고, 판정은 설계상
  답변을 안 바꾼다. 끄기의 효과로 읽을 근거가 없다
