# 재작성 × 리랭커 조합 — 리랭커가 재작성을 통째로 덮어쓴다

- 검증일: 2026-08-28
- 대상: 코드 변경 없음. `evaluation/run_eval.py` 를 인자만 바꿔 조합 칸 하나를 채웠다 (`plan_log/검색-생성.md` 조합 회차)
- 비용: **외부 API 호출 0회** — 재작성 60/60 · 리랭킹 60/60 이 전부 캐시 히트였다. 캐시가 없었다면 Cohere 60호출(≈120 search unit)

## 1. 확인하려 한 것

재작성(`fuse`)과 리랭커(`cohere`)를 **둘 다 켠 칸**이 비어 있었다. 단독 이득이 재작성 +0.041 ·
리랭커 +0.152 인데, 조합이 **덧셈인지 겹침인지 깎임인지**를 못 말한다.

"임계값이 맞는가"가 아니라 **"두 축이 서로 무엇을 하는가"** 를 재는 판이다. 총합 지표로는
덧셈과 겹침이 안 갈리므로 질의별 짝짓기가 본체다.

### 3-4. 기전 — 후보는 통째로 갈리는데 결과가 같다

*"집합은 그대로이고 순서만 바뀌어서 리랭커가 지운다"* 를 가설로 세웠다가 **기각됐다.**
리랭킹 **전** 후보 50개를 직접 비교하니:

| 항목 | 실측 |
|---|---|
| 후보 50 **집합**이 같은 질의 | **0 / 60** |
| 교체된 후보 개수 | 중앙 **12** · 최소 3 · 최대 28 (/50) |

즉 재작성은 리랭커에 **다른 후보 뭉치**를 준다. 그런데 리랭킹 **후**를 보면 상위로 갈수록
차이가 사라진다:

| 최종 상위 n | 순서까지 같음 | 집합 같음 |
|---|---|---|
| 1 | **60 / 60** | 60 / 60 |
| 3 | 55 / 60 | 55 / 60 |
| 5 | 49 / 60 | 49 / 60 |
| 10 | 34 / 60 | 34 / 60 |
| 20 | 13 / 60 | 13 / 60 |
| 50 | 0 / 60 | 0 / 60 |

**1위는 60/60 완전히 같다.** 재작성이 새로 데려온 후보 12개는 리랭커 점수로 상위권에 못 든다.

그리고 갈리는 자리와 정답 자리가 **다르다** — 최종 상위 10이 바뀐 질의가 26/60 인데,
**그중 25건은 정답 순위가 그대로다.** 바뀌는 것은 정답이 아닌 자리들이다.

## 5. 판정

- **겹침이다 — 그것도 완전 포함이다.** 재작성이 고친 20건을 리랭커가 20/20 이미 고쳤고,
  재작성만 고친 질의는 0건이다. 조합은 리랭커 단독을 **한 건도 못 이겼다**(58 같음 · 0 나음 · 2 못함).
  덧셈도 깎임도 아니다 — 리랭커가 재작성을 **흡수한다**. **의도한 변화**(재려던 것을 쟀다)
- **「후보가 같아서 결과가 같다」는 아니다.** 후보 집합은 60/60 전부 다르고 중앙 12개가 갈린다.
  같아지는 것은 **리랭커를 통과한 뒤**이고, 1위는 60/60 동일이다. 가설을 세우고 재서 **기각**했다
- **검색 지표가 같다고 파이프라인이 같은 것은 아니다.** 최종 상위 10이 26/60 에서 다른데
  지표가 안 움직인 이유는 그 차이가 **정답이 아닌 자리**에서 나기 때문이다(25/26).
  생성에 넘어가는 근거 목록은 실제로 다르다
- **비용 축은 그대로 남는다.** 재작성은 질의당 LLM 1회(+약 2초, `verify_log/2026-08-27-재작성-지연.md`)인데
  리랭커를 켠 상태에서 이 60건이 사는 것은 **검색 지표 0**이다

## 7. 재지 못한 것

- **`local-gpu` 칸** — 이번에 잰 것은 `cohere` 하나다. 「흡수」가 리랭커 종류를 타는지는 못 답한다
  (다만 `local-gpu` 단독이 `cohere` 보다 약하므로 흡수가 **덜** 될 여지는 있다)
- **`replace` 칸** — 재작성 모드를 하나만 쟀다
- **사람 세트 18건** — 실사용에 가까운 쪽에서 같은 결론이 나오는지 안 쟀다
- **생성 품질** — 최종 근거 목록이 26/60 에서 다른데 **그 차이가 답을 좋게 하는지 나쁘게 하는지
  잴 자[尺]가 없다**(골든 답변 없음). 검색 지표가 같다는 것이 답이 같다는 뜻은 아니다
- **Cohere 라이브 응답** — 전량 캐시 히트라 이번 실행은 API 를 안 불렀다. 캐시 키가 후보 순서까지
  담으므로 재현성은 보장되지만, *지금* Cohere 가 같은 점수를 주는지는 안 쟀다
