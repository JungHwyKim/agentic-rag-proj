# 용어

**이 저장소 안에서만 특별한 뜻을 갖는 말**만 모은다. 일반 RAG 용어(임베딩·청킹·재랭킹)는
적지 않는다 — 적으면 두 번째 진실이 되고 밖에서 이미 잘 설명된다.

## 적재

| 말 | 뜻 |
|---|---|
| **리전** (`ContentRegion`) | 문서 안의 «어디에 무엇이 있는가» 한 조각. 문서 로더가 내놓는 유일한 산물이고, **어떻게 텍스트로 만드는가는 안 담는다** |
| **요소** (`Element`) | 리전이 콘텐츠 핸들러를 지나 텍스트가 된 것. **청크가 아니다** — 자수 중앙값이 15~40자라 splitter 의 주 작업은 자르기가 아니라 **병합**이다 |
| **1차 / 2차 라우팅** | 1차는 `FileFormat` → 문서 로더, 2차는 `ContentType` → 콘텐츠 핸들러. 로더 **안에서** 두 번 일어난다 |
| **승급** | 무료 경로가 잡은 것을 유료 경로로 올리는 것(`table_native` → `table_vision`). **표를 다시 읽는 것이 아니라 빈 칸만 채운다** |
| **강등** | 표로 잡힌 것을 본문 문단으로 내리는 것(`_is_layout_box`). `metadata["layout_table"]` 이 남아 «강등» 과 «애초에 표가 없음» 이 갈린다 |
| **서명** (mark signature) | 표 안 표시의 벡터 경로 모양. Vision 을 **문서당 1회가 아니라 서명당 1회** 부르는 것이 요점이다 |
| **격자 구멍** | `find_tables()` 가 셀 사각형을 아예 안 낸 자리. **병합에 덮인 자리와 다르다** — `row.cells[j] is None` 이 두 뜻을 갖는다 |
| **레이아웃 표** | 한글이 제목·인용을 그리려고 쓴 표. 내용 든 칸 2개 이하 · 9칸 이하면 강등한다 |

## 질의

| 말 | 뜻 |
|---|---|
| **갈래** (branch) | RRF 에 들어가는 순위 목록 하나. `fusion.py` 는 **N 개**이고 재작성 `fuse` 모드가 넷을 쓴다 |
| **`fuse` / `replace`** | 재작성 모드. `fuse` 는 원 질의 갈래를 **남기고** `replace` 는 갈아끼운다 |
| **신참** | 재작성이 데려온, 원 질의 pool 에는 없던 후보 |
| **제3의 상태** | 판정이 *충분* 도 *불충분* 도 아닌 `verdict="failed"`. 접으면 **죽은 판정자가 만점**을 받는다 |
| **부정 예시** | 코퍼스에 답이 없는 질의. 검색 채점에서 **빠진다**(`hit@k` 가 정의상 만점이고 `recall` 은 분모가 0이라 지표가 아니라 상수가 된다) |
| **음성 대조군** | 같은 답변에 **다른 문서의 근거**를 물려 같은 판정을 시키는 것. `supported` 가 나오면 그 회차의 지지 수치는 못 쓴다 |

## 캐시와 재현

| 말 | 뜻 |
|---|---|
| **salt** | 호출 캐시 키에 섞는 설정값. **잣대가 하나다 — 출력을 가르는 것만 넣는다**(그래서 `rerank_device` 는 넣고 `rewrite_mode` 는 안 넣는다) |
| **지문** (`pipeline_fingerprint()`) | 답변 캐시가 «같은 파이프라인이 낸 답인가» 를 보는 값. salt 와 **반대 규칙**이다 — 기본은 싣고 뺄 것만 명시한다(틀리는 방향이 비대칭이라) |
| **회계 게이트** | 지표를 읽기 **전에** 유료 호출이 실제로 다 돌았는지 세는 검사. 갈래마다 세는 칸이 다르다 |

## 기록

| 말 | 뜻 |
|---|---|
| **회차** | `plan_log/<기능>.md` 안의 한 판. 파일은 기능당 하나이고 회차가 쌓인다 |
| **자[尺]** | 무엇을 재는 잣대. **적재·검색·생성의 자가 서로 달라 섞지 않는다** |
| **다시 볼 조건** | 기각한 안에 딸리는 «무엇이 생기면 재판정하나». 없으면 «없음» 이라고 적는다 |
| **가상 데이터 / 실제 데이터** | `verify_log/` 가 갈라 적는 축. 가상은 «규칙이 도는가» 에만 답하고 **임계값을 못 정한다** |
| **열린 채로 적힌 것** | `openwork` 가 내는 것. 「열린 것」이 아니다 — 다른 파일의 회차가 닫은 것은 안 빠진다 |
