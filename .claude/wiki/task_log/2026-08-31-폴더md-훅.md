## 2. 설계 결정

### 막지 않고 실어 준다 — 우회가 곧 실패이기 때문이다

첫 후보는 차단이었다(`cat` 을 deny 하고 `Read` 를 권한다). **기각했다.**

`heredoc_write_check` 의 ① 갈래는 우회해도 목적(파일 쓰기)이 달성되지만 **여기서는
반대다** — `cat f | cat` 한 번이면 통과하는데 **통과한 그 순간이 원래 문제 상황**이다.
게이트가 형식만 남는다. 거기에 셋이 더 붙는다: auto mode 와 매 턴 부딪히고, 이미 로드된
뒤에도 계속 막고(훅은 컨텍스트를 못 본다), `python -c` 안의 읽기는 탐지도 못 한다.

**주입은 넷 다 없다.** 그래서 「주입이 되는가」가 갈림길이었고, 문서로 확인이 안 돼
(페이지가 두 번 다 잘렸다) **표식으로 쟀다.** 된다.

### `permissionDecision` 을 일부러 안 낸다

`"allow"` 를 함께 내면 훅이 배선된 동안 **모든 셸 명령이 권한 프롬프트를 건너뛴다.**
목적과 무관한 권한 완화라 탐침 단계부터 빼 뒀고, 실물에서도 안 낸다 —
`additionalContext` 만으로 목적이 달성된다. **테스트로 잠갔다**
(`test_hook_never_emits_a_permission_decision`).

### 폴더당 세션 1회가 이 훅의 절반이다

없으면 **역효과다.** `evaluation/CLAUDE.md` 는 37,141바이트라 `cat` 마다 실으면 다섯 번에
분산 전 뿌리(147,014바이트)보다 나빠진다 — 즉 대책이 문제를 되살린다. 네이티브 지연
로드도 같은 파일을 두 번 안 넣으므로 마커는 **그 동작을 흉내 내는 것**이다.

마커는 `_hookutil.claim_session()` 을 쓰되 **경로를 해시해 네임스페이스로 삼는다** —
`_marker_path()` 가 네임스페이스를 **디렉터리 이름**으로 쓰기 때문에 슬래시를 그대로 넣으면
안 된다.

### 조상을 전부 모은다 — 관측이 설계를 바꿨다

`Read` 로 `…/loader/document/pdf.py` 를 읽혔더니 `ingestion/CLAUDE.md` 만 실리고
**`…/loader/CLAUDE.md` 는 안 실렸다.** 「앞서 이미 로드」인지 「조상 하나를 건너뜀」인지
**못 갈랐다.** 그래서 훅이 조상을 전부 모아 안 집힌 것만 싣는다 — **어느 쪽이 참이든
덮인다.** 하나만 골랐으면 나머지 경우가 조용히 빈다.

### 압축 리셋은 넣되 «안 쟀다» 를 적어 둔다

마커의 유일한 대가는 압축이다. `InstructionsLoaded` payload 에 `load_reason` 칸이 있고
`nested_traversal` 이 오는 것은 봤는데 **`compact` 는 못 봤다**(압축을 일으키지 않았다).
넣어 두는 쪽을 고른 것은 **틀리는 방향이 안전해서**다 — 값이 안 오면 지금처럼 안 실릴 뿐,
잘못 실리지는 않는다. 반대로 리셋을 넓게 잡으면(모든 `InstructionsLoaded` 에 지우기) 중복
방지가 통째로 무너지므로 그쪽은 테스트로 막았다.

### 상한을 안 뒀다

한 명령이 여러 폴더에 걸치면 지침이 여러 개 실린다. 상한을 두면 **내용을 조용히 자르게**
되고, 그건 이 저장소가 반복해 피하는 모양이다. 실제로 아픈지는 안 쟀다 — 7절.

## 4. 실패 분석

- **훅이 한국어 한 글자에 죽었다.** 자기검사에서 `UnicodeEncodeError: 'cp949' codec` 로
  종료코드 1. CLAUDE.md 가 「출력」 얼굴로 적어 둔 그 함정이고 처방도 거기 적힌 대로다 —
  `main()` 이 `sys.stdout.reconfigure(encoding="utf-8")` 로 **자기 출력을 스스로 못 박는다**
  (호출하는 쪽 규약으로 두면 안 붙인 호출에서만 깨진다). **훅이 죽으면 지침이 «안 실린
  것» 이 되는데 아무 에러도 안 난다** — 자기검사를 안 했으면 그대로 배선했다
- **`contextlib` import 를 빼먹고 14개를 깨뜨렸다.** ruff `SIM105` 를 따라
  `contextlib.suppress` 로 바꾸면서 import 를 안 넣었다. `auto_test_check` 가 즉시 잡았다
- **기록을 고치다 백틱이 명령 치환으로 먹혔다.** `python -c "…"` 의 **큰따옴표 안 백틱**을
  셸이 실행해 `wc -c`·`/context` 같은 식별자가 문서에서 **빈 문자열로 사라졌다.** 메모리에
  적어 둔 함정을 그대로 밟았고, **종료 코드가 0이고 「ok」 가 찍혀** 넘어갈 뻔했다 —
  가른 것은 쓴 자리를 눈으로 다시 읽은 것 하나다. 처방은 스크립트 파일로 쓰는 것
- **`.claude/settings.json` 편집이 auto mode 분류기에 막혔다.** 우회하지 않고 사용자에게
  넘겼고, 그동안 탐침 파일을 스크래치패드로 **옮겨** 트리를 초록으로 되돌렸다(지우지 않았다).
  사용자가 권한을 준 뒤 이어서 했다
- **사용자가 보고한 첫 «모른다» 는 무효였다.** 그 시점에 탐침이 `.claude/hooks/` 에도
  없고 배선도 없고 덤프도 없었다 — 내가 방금 트리를 되돌려 놓은 상태였다. **결과를 받자마자
  배선 상태부터 확인한 것이 갈랐다**(안 했으면 «주입이 안 된다» 로 결론 내고 차단안으로
  갔을 것이다)
