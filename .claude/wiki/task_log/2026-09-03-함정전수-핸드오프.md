## 2. 제일 큰 함정 — 「없음」을 「낡음」으로 세면 정반대가 된다

**먼저 적는다.** 이 문서에는 ***일부러 없다는 것을 말하는 주장***이 실재한다.

- *"`search()` 에 `filters` 인자가 없는 것은 누락이 아니다"*
- *"빈 `frontend/` 가 2026-08-31 에 지워졌다"*
- *"`.hwp`/`.doc`/`.ppt` 는 `SUPPORTED_EXTENSIONS` 에 **포함돼 있다**"*(빼면 안내가 망가진다)

기계가 이런 항목을 «식별자가 코드에 없다 → 낡았다» 로 세면 **정확히 거꾸로다.**
그래서 **기계는 후보만 좁히고 판정은 읽어서 한다.** 위 셋이 「거짓」으로 나오면 그것은
규칙이 아니라 **판정이 틀린 것**이고, 검증 항목으로 못 박아 뒀다(6절).

## 3. 어떻게 재나 — 2단계

**1단계 — 기계 훑기(후보 좁히기).** 백틱 식별자를 전수로 뽑아 **실재 여부**만 찍는다.

- `` `foo/bar.py` `` → 그 파일이 있나
- `` `_symbol` `` · `` `func()` `` · `` `CONFIG_KEY` `` → 저장소에 있나
  (`rag_pipeline/**` · `backend/**` · `evaluation/**` · `tests/**` · `.env.example`)

스크립트는 스크래치패드에 두고 **저장소에 남기지 않는다**(한 번 쓰고 버리는 탐침이다).

**2단계 — 사람이 읽어 판정한다.** 1단계 후보에 더해 **관계 주장**을 읽는다 —
*"여전히 `max_tokens=` 를 쓴다"* 가 전형이고, **심볼이 존재해도 주장은 거짓일 수 있다.**
1단계가 원리적으로 못 잡는 갈래다.

**판정 단위는 항목이 아니라 문장이다.** 표의 행은 함정이 아니라 그 안의 한 주장이다.
판정 셋 — **참 / 거짓 / 확인 필요**(읽어도 못 가른 것. 억지로 결론 내지 않는다).

## 4. 규모와 세는 명령

실측(`2639838` 기준) — 파일 이름을 짚는 항목 **28** · 심볼·설정키를 짚는 항목 **32** ·
**둘 중 하나라도 40개** · 실측 수치를 담은 항목 **39개**(크게 겹친다).

즉 **판정 대상이 있는 항목이 40개**이고, 나머지 14개는 코드에 댈 것이 없다.

```bash
./.venv/Scripts/python.exe -c "import pathlib,re;c=pathlib.Path('CLAUDE.md').read_text(encoding='utf-8');s=c.split('## 알고 있어야 할 함정')[1].split(chr(10)+'## ')[0];b=[x for x in re.split(r'\n(?=- [*][*])',s) if x.strip().startswith('- **')];print(len(c),'자 · 함정',len(b),'개',len(s),'자')"
```

## 6. 검증 — 판정이 성립하는가

1. **회계** — 뽑은 식별자 수 = 실재 + 미실재. 미실재 후보는 **전수로 눈으로** 본다
2. **「일부러 없다」를 안 뒤집었나** — 2절의 세 예시가 「거짓」으로 안 나오는지 **손으로**
   확인한다. 나오면 판정이 틀린 것이다
3. **기준점이 안 움직였나** — 끝에 `git log --oneline -1` 이 `2639838` 인지 본다.
   다르면 갈린 항목만 다시 본다

```bash
./.venv/Scripts/python.exe openwork/collect.py
```


## 7. 배경 — 이 문제가 어떻게 열렸나

17회차가 **«뿌리를 줄이는 길» 둘을 닫았다** — 폴더 분리(15회차 · 훅 채널에서 15.9% 잘림)와
포인터만 남기기(17회차 · 지침 포인터 도달률 **0.335** 대 기준선 0.822). 둘 다
**«다른 데로 옮긴다»** 였다.

남은 셋째 길은 **옮기지 말고 CLAUDE.md 안에서 줄이는 것**인데 규칙 하나에 막혀 있다 —
*"원문을 한 글자도 안 고친다"*(10회차 미결). **그런데 그 규칙과 무관하게 지울 수 있는 것이
하나 있다: 이미 거짓이 된 줄.** 참이 아닌 문장은 «그때의 사실» 이 아니라 그냥 오류다.

**그것을 아무도 세어 본 적이 없다.** 이 회차가 우연히 표본 하나를 확인했을 뿐이다(5절).

**대응표가 준 상한도 함께 읽는다** — 전문이 knowledge 에 있는 것(①)은 **18,380자로 함정 절의
44.7%뿐**이고, 나머지 55.3%는 CLAUDE.md 가 유일한 집이다. 게다가 **큰 항목일수록 옮길 데가
없다**(제일 큰 여덟 중 다섯이 ②·③). 그래서 「덩치 큰 것부터 정리」라는 자연스러운 순서가
정확히 못 줄이는 것부터 건드린다.
