## 2. 설계 결정

### 도구만 만들고 Router·loop 은 한 줄도 안 건드렸다

`router.py` 가 *"`web_search` 를 고를 신호가 없다"* 를 근거와 함께 잠가 뒀고 `loop.py` 는 그
액션이 오면 **일부러 `RuntimeError` 로 터진다.** 배선까지 가려면 *「이 질문이 코퍼스 밖인가」*
를 실행 시점에 판정할 신호를 세워야 하는데, 그것은 규칙이 아니라 **측정**이 딸린 별개 판이다.

**버린 안**: 「재시도를 다 썼는데 verdict 가 여전히 *불충분*」을 코퍼스 밖 신호로 삼기.
Phase 4·Checkpoint A 가 생겨 신호 자체는 실재하지만, 그러면 `NextAction` 분기 ·
`step_budget()` · `graph.py` 가 함께 움직이고 **「웹으로 답했다」를 화면·`query_log` 에서
가르는 결정**이 딸려 온다. 사용자가 면담에서 범위를 도구로 좁혔다.

**감수 사항을 감추지 않는다** — 이번 판의 도구 넷은 **자동으로는 아무도 안 부른다.**

### 결과를 전용 스키마가 아니라 `RetrievedChunk` 로 맞췄다

`WebResult(title, url, content, score)` 를 만들면 정직하지만 **근거 블록 모양이 두 벌**이 된다.
`agent/context.py` 가 *"세 번째 모양이 끼면 세 곳 중 한 곳만 고쳐져도 아무 에러가 안 난다"* 로
막아 둔 자리가 정확히 거기다.

맞춘 결과가 실측으로 나왔다 — **근거 조립 코드를 한 줄도 안 고치고** 실제 Tavily 결과가
`[1] (행정정보 데이터세트 기록관리 적용 사례 분석)` 꼴로 렌더됐다. `generation/citations.py`
의 인용 번호 검사도 공짜로 붙는다.

대가는 웹 결과에 뜻이 없는 칸이 생기는 것이고, `metadata["origin"] == "web"` 하나가 가른다.

### 점수 칸을 안 채운다

`dense_score` · `rewrite_dense_score` · `fused_score` · `rerank_score` 넷은 전부 **코퍼스 검색
경로의 산물**이다. Tavily 의 relevance(`0.898…`)를 거기 담으면 `evaluation/` 의 지표와
`rerank_diff.py` 가 **두 척도를 한 칸에서 읽는데 에러가 안 난다.** 그래서 Tavily 점수는
`metadata["web_score"]` 로 간다.

다시 정렬하지도 않는다 — `context.py` 의 *"다시 정렬하지 않는다"* 가 그대로 적용되고, 여기서는
Tavily 가 준 순서가 곧 그 순서다.

### `WEB_SEARCH_PROVIDER` 를 안 만들고 `WEB_SEARCH_DEPTH` 는 만들었다

같은 잣대(*"고를 축이 실재할 때만 설정이 생긴다"*)가 한 파일 안에서 반대 답을 낸다.
제공자는 Tavily 하나뿐이라 합법값이 하나인 **죽은 설정**이고(`rerank_provider` 가 셋이라
있는 것의 반대쪽 사례), 깊이는 `basic`/`advanced` 가 **크레딧을 갈라** 축이 실재한다.

**SDK 는 `fast`·`ultra-fast` 도 받는데 안 열었다** — 그 둘의 크레딧·품질을 안 재 봐서다.
**합법값을 설명하지 못할 설정은 만들지 않는다.**

### 호출 캐시를 안 붙였다

이 저장소의 캐시 셋(`.cache/embedding`·`rerank`·`rewrite`)은 전부 **같은 입력이면 같은 출력**이
참이라 내용 해시만으로 키가 선다. 웹 검색은 그것이 **거짓**이다 — 결과가 시간에 따라 변하는
것이 이 도구의 존재 이유라, TTL 없이 붙이면 «최신을 찾는 도구가 옛 답을 준다» 가 **에러 없이**
생긴다. TTL 값을 정하려면 「웹 결과가 얼마 만에 낡나」를 재야 하는데 그 자[尺]가 없다 —
이 저장소의 임계값은 전부 분포의 틈에서 나왔다.

**대가를 세 곳에 적었다**(설정 주석 · `.env.example` · `tools/__init__.py`). 다른 유료 단계는
전부 캐시가 있어서 **없는 것이 누락으로 보이고**, 그러면 누군가 좋은 뜻으로 붙인다.

### 날짜는 `zoneinfo` 가 아니라 고정 오프셋이다

`zoneinfo.ZoneInfo("Asia/Seoul")` 은 **시스템 tz 데이터베이스**를 찾는데 Windows 에는 없어
`ZoneInfoNotFoundError` 가 난다(`tzdata` 를 따로 깔아야 한다). 개발·운영 머신이 Windows 라
의존성을 하나 더 들이는 대신 `timezone(timedelta(hours=9))` 를 쓴다 — **한국은 서머타임이
없어 UTC+9 가 영구히 참**이므로 이 축에서는 근사가 아니라 정확한 값이다.

**UTC 가 아닌 이유**는 `ToolCallLog.timestamp` 와 축이 달라서다. 저쪽은 *언제 기록됐나*
(기계의 시각), 이쪽은 *사용자가 사는 달력*이다. 「이번 달」을 UTC 로 답하면 한국 시간 오전
9시 이전에 날짜가 하루 어긋난다.

**버린 안**: `astimezone()` 을 그냥 부르기. naive 시각을 **머신의 로컬 시간**으로 읽어,
테스트가 도는 머신에 따라 날짜가 갈리는데 에러가 안 난다. naive 는 KST 로 *선언*한다.

### 계산기는 화이트리스트 + 지수 상한 **둘 다**

`eval()` 은 곧 임의 코드 실행이고(입력이 모델이 쓴 문자열이다), `ast.literal_eval()` 은
**연산을 아예 못 한다**(`1+1` 이 3.8부터 거절된다). 그래서 `ast.parse()` + 허용 노드 방문이다.
화이트리스트라 왈러스·f-string·comprehension 같은 새 문법이 **저절로** 막힌다 —
블랙리스트였으면 문법이 늘 때마다 따라 고쳐야 하고, 안 고치면 조용히 열린다.

**그런데 화이트리스트가 못 막는 축이 하나 있다.** `2 ** 99999999` 는 문법이 멀쩡하고 허용
노드만 쓰는데 계산하다 메모리를 태운다. 「무엇을 쓰나」와 「얼마나 크나」가 다른 축이라
지수 상한(100)이 따로 있다. 거듭제곱만 지수적이라 이 축이 여기 하나다.

`True + 1` 을 거절하는 것도 같은 종류의 구멍 메우기다 — `isinstance(True, int)` 가 참이라
안 거르면 2 가 나오고, **산술식이 아닌 것이 답을 내면 계산기가 아니라 인터프리터다.**

### 실패 사유를 도구가 직접 만든다

`BaseTool.run()` 이 예외를 값으로 바꿔 주지만, 그러면 사유가 `ZeroDivisionError: division by
zero` 로 시작해 **사람이 못 읽는다.** `NOT_CONFIGURED` 를 예외 이름으로 시작하지 않게 한 것과
같은 잣대다. 계약을 대신하는 것이 아니라 **두 겹**이다 — 여기서 못 잡은 것은 `run()` 이 받는다.

### 문서목록은 `getattr` 로 받는다

`list_documents()` 는 `VectorStore` Protocol 에 **일부러 안 올라가 있다** — 저장소 중립을
지키는 쪽이 그것이고, 두 번째 구현체가 실재할 때 올린다. `backend/app/main.py` 와
`routes/query.py` 가 이미 `getattr` 규약을 쓴다. **타입으로 요구하면 Protocol 을 넓히게 되는데
그 결정은 도구가 내릴 것이 아니다.**

## 4. 실패 분석

### 픽스처를 먼저 넣었는데도 실키가 샜다 — **그 픽스처가 틀렸다**

계획서에 *"부수 효과는 배선보다 먼저 막는다"* 를 적고 `tests/agent/conftest.py` 를 **구현보다
먼저** 넣었다. 그런데도 `auto_test_check.py` 가 구현 직후 돌린 `tests/agent` 가 **Tavily 를
실제로 2회 쳤다.**

초판은 이것이었다.

```python
monkeypatch.delenv("TAVILY_API_KEY", raising=False)
```

**pydantic-settings 는 환경변수와 `.env` 파일을 둘 다 읽는다.** 환경변수를 *지우는* 것은
파일 쪽을 안 건드려서, 지운 자리를 `.env` 가 곧바로 채웠다. 고친 것은 한 줄이다 —
`monkeypatch.setenv("TAVILY_API_KEY", "")`. 빈 문자열이 falsy 라 `_make_client()` 가 `None` 을
돌려준다.

**왜 이렇게 짰나**가 이 항목의 핵심이다. `tests/api/conftest.py` 의 autouse 핀
(`ORIGINALS_DIR`·`QUERY_LOG_PATH`)을 본보기로 삼았는데, **저쪽은 덮어쓰기고 이쪽은 지우기라
방향이 반대**다. 덮어쓰면 환경변수가 파일을 이기고, 지우면 파일이 남는다. 자리도 모양도 같아
보이는데 결과가 정반대라 **베끼는 순간 조용히 안 먹는다.**

증거 둘이 남았다.

| 픽스처 | `WebSearchConfig().tavily_api_key` | `tests/agent` |
|---|---|---|
| `delenv(...)` | **키가 실린다** | 2 failed · **4.89초** |
| `setenv(..., "")` | 비었다 | 87 passed · **0.85초** |

**시간 차 자체가 왕복의 증거다.** 그리고 실패 메시지가 둘 다 서버가 준 것이었다 —
`chunk_id='web:https://www.kdca.go.kr/...'` 와 `BadRequestError: Query is too short.`

**가짜 키를 넣는 안은 더 나쁘다** — `_make_client()` 가 클라이언트를 실제로 만들어
**네트워크까지 간 뒤** 401 로 죽는다. 막으려던 것이 호출인데 호출이 나간다.

**`paid_test_check.py` 는 이것을 원리적으로 못 막는다.** 그 훅이 막는 것은 `-m integration`
이고 이건 기본 마커다. 즉 **유료 호출이 기본 pytest 로 새는 두 번째 경로**이고, 지금 이 자리를
지키는 것은 훅이 아니라 픽스처 하나다.

**2026-08-26 의 `QUERY_LOG_PATH` 유출과 축이 다르다.** 저기서 얻은 교훈은 *"가른 것은 지식이
아니라 순서"* 였는데, 이번엔 **순서를 지켰다.** 가른 것은 `auto_test_check.py` 가 구현 직후
실제로 테스트를 돌린 것 하나다 — 그 훅이 없었으면 커밋될 때까지 몰랐다.

### 큰 heredoc 이 셸 파서에서 깨졌다

`verify_log/` 기록을 `cat > … <<'MD'` 로 쓰려다 `unexpected EOF while looking for matching '`
로 죽었고 **파일이 아예 안 만들어졌다.** 짧은 heredoc 들은 같은 세션에서 멀쩡히 돌았으므로
따옴표 규칙 문제가 아니라 길이·내용 조합으로 보이는데 **원인을 못 좁혔다.** Write 도구로
갈아타 해결했다. 이 항목은 「막다른 길」로 남긴다 — 다음 사람이 같은 방식으로 긴 한국어
마크다운을 쓰려다 같은 자리를 밟는다.

### 없던 것: SDK 응답을 짐작하는 것

밟지는 않았지만 **밟을 뻔한 자리**라 적어 둔다. LlamaParse 의 `markdown` 을 문자열로 알고
`.strip()` 을 부르다 적재 전체가 멈춘 선례(2026-08-18)가 정확히 이 종류라, 가짜 응답을 짓기
**전에** 설치된 SDK 소스를 읽었다. 얻은 것 셋 — `search()` 의 반환 타입 주석이 `dict` 이고,
`results` 를 `setdefault` 로 보장하며, 200 이 아니면 **예외를 던진다**. 그래서 가짜의 모양이
관측에서 나왔고 「0건」과 「HTTP 실패」 테스트가 실제 동작을 잰다.

## 7. 남은 것

- **Router 가 `web_search` 를 고르게 하는 것** — 신호를 세우고 재야 한다. `router.py` 의
  「다시 볼 조건」은 그대로 살아 있고 이번 판이 그 절반(도구 구현)만 채웠다
- **`paid_test_check.py` 의 구멍** — 유료 호출이 `-m integration` 밖으로도 샌다는 것이
  이번에 실측됐다. 훅을 고칠지, 픽스처 규약으로 둘지는 **정한 적이 없다** → `plan-log` 감
- **`search_depth` 의 `fast`·`ultra-fast`** — SDK 는 받는데 크레딧·품질을 안 쟀다
- **`web_search_max_results=5`** — 임시값이다. 웹 근거가 답변에 실리는 경로가 없어 못 정한다
- **호출 캐시** — 안 붙였다. TTL 을 정하려면 「웹 결과가 얼마 만에 낡나」를 재야 한다
- **커밋** — 안 했다. 같은 트리에 다른 세션 둘이 붙어 있어 **임시 인덱스로 내 파일만**
  스테이징해야 한다(내 파일 목록은 1절)
