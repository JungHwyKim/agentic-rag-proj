# 질의 재작성(Phase 5) 구현 검증 — 동등성 18/18, 유료 경로는 안 밟았다

- 검증일: 2026-08-27
- 대상: Phase 5(질의 재작성) 구현 — `task_log/2026-08-27-질의재작성-구현.md`
- 비용: **외부 API 호출 없음.** `.cache/rewrite` 파일 수가 **0 → 0**(재작성 호출 0회) ·
  `.cache/rerank` **630 → 630** · `.cache/evaluator` **430 → 430**. 동등성 실행은
  `--embedding kure-v1`(로컬 KURE-v1) · `--rerank off` 라 과금 경로가 없다

## 1. 확인하려 한 것

둘이고 성격이 다르다.

1. **규칙이 도는가** — 재작성기가 켜지고·꺼지고·실패하고·캐시에 걸리는가, `fuse` 와
   `replace` 가 실제로 다른 갈래를 도는가. **가상 데이터로 답한다**
2. **기존 경로가 안 움직였는가** — `fuse()` → `fuse_branches()` 리팩터와 `widen` 확장이
   `rewriter=None` 경로를 건드렸는지. **실파일 + 기존 리포트 대조로 답한다**

**임계값을 정하는 검증이 아니다.** 이 회차는 값을 재지 않았다 — 재작성이 값을 하는지는
유료 실행에서만 나오고, 그것은 안 돌렸다(7절).

## 2. 가상 데이터

무엇을 고립시켰나: **질의 문자열 하나만** 갈래를 가르게 만들었다. 가짜 임베더가 질의 길이를
벡터 0번 성분에 실어 나르고, 가짜 저장소가 그 값으로 원 질의와 재작성 질의를 갈라 **서로 다른
결과**를 준다. 안 그러면 두 모드가 같은 것을 합쳐 **통과하면서 아무것도 안 잰다.**

```python
# tests/retrieval/test_rewrite.py — 전문은 저장소에 있다. 핵심은 이 셋이다
_ORIGINAL  = "개인정보를 함부로 지우면 어떻게 되나요"
_REWRITTEN = "공공기록물 관리에 관한 법률 벌칙 손상 제51조"

class FakeEmbedder:                      # 질의를 벡터 자리에 실어 나른다
    def embed_query(self, text): return [float(len(text)), 0.0, 0.0]

class FakeStore:                         # 그 값으로 갈래를 가른다
    def __init__(self, by_query):
        self._by_query = by_query
        self._lengths  = {float(len(q)): q for q in by_query}
    def search(self, query_vector, top_k=5):
        return self._by_query.get(self._lengths.get(query_vector[0]) or "", [])[:top_k]

_store = FakeStore({
    _ORIGINAL:  [_result("a", 0.82), _result("b", 0.71)],
    _REWRITTEN: [_result("c", 0.93), _result("a", 0.40)],
})
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| `rewrite_model=None` | `get_rewriter()` 가 `None` | `None` | 통과 |
| `rewrite_model` 있고 키 없음 | 객체는 생긴다(꺼짐은 이름이 정한다) | 생김 | 통과 |
| `rewriter=None` 로 `retrieve()` | `["a","b"]` · `fused_score` 가 저장소 점수 그대로 · 호출 0 | 동일 | 통과 |
| `replace` | `["c","a"]` · `dense_score` 전량 `None` · `rewrite_dense_score` 0.93 | 동일 | 통과 |
| `fuse` | `{a,b,c}` · `a` 는 두 칸 다 참(0.82 / 0.40) · `b` 는 재작성 칸 `None` | 동일 | 통과 |
| 두 모드 결과 대조 | **달라야 한다** | 다름 | 통과 |
| 응답 손상 6종 | 전부 `None` · `api_calls` 0 · 경고 1줄 | 전부 그럼 | 통과 |
| 호출 예외(`RuntimeError("429")`) | 예외가 안 새고 경고에 `429` | 동일 | 통과 |
| 재작성 실패 후 결과 | **재작성 안 켠 결과와 같아야** | 순위·`fused_score` 동일 | 통과 |
| 1차 결과 0건 | 호출 안 함 | `calls == []` | 통과 |
| 같은 (질의, 후보) 두 번 | 2회차가 캐시 히트 · 호출 1회 | 동일 | 통과 |
| **`fuse` 로 캐시 채운 뒤 `replace`** | **캐시 히트**(salt 에 mode 없음) | 히트 · 호출 1회 | 통과 |
| 손상 응답 두 번 | 캐시에 안 들어가 호출 2회 | 2회 | 통과 |
| `rewriter` 켰을 때 저장소 `top_k` | `candidate_k=50` 으로 넓힘 ×2 | `[50, 50]` | 통과 |
| BM25 함께 | 갈래 넷 — BM25 전용 후보 `d` 가 있고 `rewrite_bm25_score` 가 참 | 동일 | 통과 |
| 리랭커에 넘어간 질의 | **원 질의** | `[_ORIGINAL]` | 통과 |
| `rewrite_temperature=None` | `temperature` 인자 자체가 없음 | 없음 | 통과 |
| 호출 인자 | `max_completion_tokens` 있고 `max_tokens` 없음 | 동일 | 통과 |
| `rewrite_context_k=2` · 후보 5 | 프롬프트에 `[0]`·`[1]` 만 | 동일 | 통과 |

**여기서 정한 임계값은 없다.** 전부 *"규칙이 도는가"* 이고, 값을 정하는 것이 아니다.

## 7. 재지 못한 것

- **재작성이 값을 하는지** — 유료다. `--rewrite fuse` · `--rewrite replace` 를 안 돌렸다.
  **지표를 읽기 전에 `usage.rewrite_calls + rewrite_cache_hits == 질의 수` 를 먼저 확인한다**
  (Cohere 1차 실행이 한도 초과 30건을 품질 저하로 읽히게 했던 자리와 같은 입구다)
- **모델이 사람만큼 다시 쓰나** — 21회차 프로브의 `honest` 는 **사람이 코퍼스를 알고** 썼다.
  모델이 `시청각`·`실행방안` 같은 낱말을 낼지는 여전히 안 쟀다. **첫 유료 측정의 첫 물음이다**
- **`fuse` vs `replace`** — 이 회차가 만든 것은 **묻는 장치**이지 답이 아니다.
  프로브의 `102위 → 2위` 와 견줄 수 있는 것은 `replace` 뿐이다
- **HWPX 판에서의 동등성** — `--format pdf` 만 돌렸다. 리팩터가 포맷을 안 타는 자리라
  (`hybrid.py`·`fusion.py` 는 청크를 포맷과 무관하게 다룬다) 안 돌렸고, **그것은 논증이지
  실측이 아니다**
- **생성 품질** — 여전히 못 잰다(골든 답변이 없다)
