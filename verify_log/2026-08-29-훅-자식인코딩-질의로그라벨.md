## 1. 확인하려 한 것

둘이고 성격이 다르다.

- **B — 규칙이 도는가.** 훅이 돌린 자식 pytest 의 **한국어** 실패 사유·skip 사유를 부모가

  차 있나. 그 줄들이 `exact` 답변 캐시를 계속 켤지의 **분모**다(`evaluation/README.md` 8절)

## 2. 가상 데이터

무엇을 고립시켰나: **자식 프로세스의 stdout 인코딩 하나만.** 같은 테스트 파일·같은 호출
모양이고 `env` 만 네 갈래로 바꿨다. 부모 쪽은 훅과 똑같이 `encoding="utf-8",
errors="replace"` 로 고정했다.

```python
# 한국어로 죽는 테스트 하나 + 한국어 사유로 건너뛰는 테스트 하나
PROBE = '''
import pytest


def test_korean_failure_message():
    assert False, "임계값이 분포의 틈에서 안 나온다"


@pytest.mark.skip(reason="실파일이 없어 건너뜁니다")
def test_korean_skip_reason():
    pass
'''


# 훅(_run_pytest)과 같은 호출 모양으로 돌리고 U+FFFD 개수를 센다
def run_probe(workdir, env):
    proc = subprocess.run(
        [PY, "-m", "pytest", "test_probe.py", "-q", "-rs", "-p", "no:cacheprovider"],
        cwd=workdir,
        capture_output=True,
        text=True,
        encoding="utf-8",
        errors="replace",
        env=env,
        stdin=subprocess.DEVNULL,
    )
    out = proc.stdout + proc.stderr
    return out.count("�")


# 기준 환경은 PYTHONIOENCODING 을 지운 것이다 — 훅이 실제로 뜨는 조건
base = {k: v for k, v in os.environ.items() if k != "PYTHONIOENCODING"}
```

| 입력 (`env`) | 기대 | 실측 U+FFFD | 판정 |
|---|---|---:|---|
| 훅 원래대로 (`base`, 안 줌) | 깨진다 | **52** | 증상 재현 |
| `base` + `PYTHONIOENCODING=utf-8` | 읽힌다 | **0** | 기대대로 |
| `base` + `PYTHONUTF8=1` | 읽힌다 | **0** | 기대대로 (채택 안 함 — 이유는 task_log 2절) |
| `_hookutil.child_env()` | 읽힌다 | **0** | 배선 확인 |

### 2-1. 새 검사가 «실패할 수 있었나»

`tests/hooks/test_hook_wiring.py::test_subprocess_text_calls_pin_child_encoding` 과 같은
규칙(`subprocess.run` 에 `encoding` 은 있는데 `env` 가 없는 호출)을 **HEAD 판(고치기 전)**
소스에 걸어 봤다.

| 파일 | HEAD (고치기 전) | 지금 (작업트리) |
|---|---|---|
| `auto_test_check.py` | **걸림 — `:168`** | 없음 |
| `pre_commit_check.py` | **걸림 — `:68`** | 없음 |

나머지 훅 다섯(`_hookutil` · `heredoc_write_check` · `paid_test_check` ·
`plan_interview_check` · `plan_log_check` · `task_log_check`)은 **양쪽 다 0건**이다 —
`encoding=` 을 주는 `subprocess.run` 호출이 없다. `_hookutil.changed_paths()` 의 `git -z`
는 바이트로 받아 직접 디코드하므로 애초에 이 규칙에 안 걸린다.

즉 새 테스트는 **어제 코드에서 실제로 두 건을 잡는다.** 보장된 통과가 아니다.

### 2-2. 헬퍼 단위 검사

`test_child_env_pins_utf8` 은 `PYTHONIOENCODING=cp949` 를 깔아 두고 `child_env()` 가
`utf-8` 로 **덮는지**와 `PATH` 를 **잃지 않는지**를 함께 본다. `test_child_env_makes_korean_readable`
은 자식을 실제로 띄워 왕복시키되, **안 박은 쪽이 깨지는 것까지** 단언한다 — 대조군 없이
성공만 재면 `child_env()` 가 빈 dict 를 돌려줘도 통과한다.

## 3. 실제 데이터

`tests/fixtures/` 는 이 작업과 무관하다. 여기서의 실제 데이터는 **관측이 쌓인 질의
로그**다.

| 파일 | bytes | sha256(12) |
|---|---:|---|
| `queries.jsonl` 고치기 전 (`scratchpad/queries.jsonl.bak`) | 23,528 | `bd146b3b326f` |
| `queries.jsonl` 고친 뒤 (`data/queries.jsonl`) | 23,531 | `f165aa0eb6d2` |

| 항목 | 고치기 전 | 고친 뒤 | 판정 |
|---|---:|---:|---|
| `source == "user"` 줄 | 3 | **0** | 의도한 변화 |
| 그중 `cached == true` | 1 | 0 | 〃 |
| `key` 완전 일치 반복 | 1 | 0 | 〃 |
| `source == "probe"` 줄 | 1 | **4** | 〃 |
| `source` 키가 없는 옛 줄 | 53 | 53 | 불변 |
| 총 줄 수 | 67 | 67 | 불변 |
| CRLF | 67 | 67 | 불변 |

**되돌림 검사** — 고친 3줄의 `"source": "probe"` 를 `"source": "user"` 로 되돌리면 원본과
**바이트가 같다**(`True`). 관측 칸(`query`·`at`·`cached`·`elapsed_ms`·`verdict` 등)은 한
바이트도 안 건드렸다.

**분모가 3이라 어떤 비율도 인용하면 안 된다.** 고치기 전 «적중률 1/3 = 33%» 는 실사용
지표가 아니라 *측정 트래픽이 만든 수* 다. 컷은 `source=="user"` 가 50줄 쌓였을 때 읽는다.

교정 대상 3줄의 신원은 이렇다(64~66번 줄).

```
64  2026-08-29T07:52:59  cached=false  elapsed_ms=6837  key=af2fd96b…
65  2026-08-29T07:55:12  cached=true   elapsed_ms=   1  key=af2fd96b…   ← 64 와 완전 일치
66  2026-08-29T07:55:45  cached=false  elapsed_ms=3773  key=70449d02…
67  2026-08-29T07:58:01  cached=false  elapsed_ms=3910  key=af2fd96b…   ← 이미 source="probe"
```

67번이 64/65 와 **같은 질의인데 이미 `probe`** 다 — 같은 측정 세션(07:52~07:58)이고 07:58
부터 헤더를 붙인 것이라, 라벨을 `probe` 로 맞추면 한 세션이 한 라벨을 갖는다.

## 5. 판정

- **B — 의도한 변화.** 훅 두 자리의 자식 인코딩이 고정됐고, 한국어 사유가 U+FFFD **52 → 0**
  으로 읽힌다. 고친 `_run_pytest` 를 한국어로 죽는 테스트에 직접 물려 반환이 `False`(실패
  보고)인 것과 사유가 읽히는 것을 함께 확인했다
- **A — 의도한 변화.** 측정 3줄이 실사용 분모에서 빠졌다. 관측은 그대로 남아 있고 되돌리면
  바이트가 같다
- **회귀 — 없음.** 전체 1922 passed 이고 skip 8건은 전부 조건 미성립·실파일 특성이다.
  `tests/openwork` 의 cp949 회귀 테스트가 `PYTHONIOENCODING=cp949` 를 **명시로** 덮으므로
  이번 변경이 그 검사를 무장 해제하지 않는 것도 확인했다(전건 통과)

## 7. 재지 못한 것

- **`pre_commit_check` 를 실제 커밋 경로로 안 돌렸다.** 호출부에 `env=` 가 붙은 것은 ast 로
  확인했고 `_hookutil.child_env()` 자체는 단위로 쟀지만, **커밋을 실제로 막는 상황을 만들어
  사유가 읽히는지는 안 봤다.** end-to-end 로 돌린 것은 `auto_test_check` 쪽 하나다.
  `tests/hooks` 에 `test_pre_commit_check.py` 가 아예 없는 것도 그대로 남아 있다
- **훅이 Claude Code 에서 실제로 뜰 때 `PYTHONIOENCODING` 이 늘 없는지 못 봤다.** 이번
  측정은 셸에서 그 변수를 지운 조건을 *만들어* 잰 것이다. 있으면 이미 안 깨졌을 것이므로
  증상이 났다는 사실이 방증이지만, 훅 환경을 직접 찍어 보지는 않았다
- **`exact` 캐시를 계속 켤지는 원리적으로 못 잰다** — `source == "user"` 가 0줄이다.
  50줄까지 기다린다. 그때까지 이 축의 어떤 수치도 나오지 않는다
- **옛 53줄의 손 분류(실사용 17줄)를 다시 안 봤다.** 이번 교정과 독립이라 그대로 유효하다고
  **가정**했고, 재검증하지 않았다
- **PYTHONUTF8=1 이 자식의 파일 I/O 에 실제로 무엇을 바꾸는지 안 쟀다.** 채택하지 않은
  근거는 *«바꾼다»* 는 문서상의 성질이지 이 저장소에서의 관측이 아니다
