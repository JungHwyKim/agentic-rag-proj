## 1. 확인하려 한 것

**둘이고 성질이 다르다.**

1. **규칙이 도는가** (가상) — 후보를 뽑나 · 라벨 없음이 `None` 인가 · 블록에 비[比]가 없나 ·
   걸린 낱말을 다 싣나
2. **설계 판정** (실데이터) — 15회차가 «어휘로 잡힌다 ✓» 로 매긴 두 건이 **실제로 잡히나**.
   이것은 임계값 문제가 아니라 **자[尺]를 고르는 문제**라, 합성 문서로는 원리적으로 못 답한다
   (합성 답변은 내가 기대한 대로 쓰이므로 자기 확인이 된다)

## 2. 가상 데이터

무엇을 고립시켰나: **답변이 금지어를 단정하나 부정하나** 한 축. 라벨·질의·근거는 고정.

```python
# tests/evaluation/test_answer_eval.py — 회귀로 박은 것 그대로
scored = _claim_row("사전에 안전성 검증을 받아야 합니다. 위험 평가도 필요합니다.")
score_must_not_claim(scored, _item(must_not_claim=["외부 안전성 검증 절차"]))

scored = _claim_row("다만, 매년 지정해야 한다는 내용은 문서에 없습니다.")
score_must_not_claim(scored, _item(must_not_claim=["매년 지정 주기"]))

scored = _claim_row("국민이 설명을 요청할 수 있습니다.")
score_must_not_claim(scored, _item(must_not_claim=["설명 대상을 국민으로"]))

scored = _claim_row("전혀 다른 이야기를 합니다.")
score_must_not_claim(scored, _item(must_not_claim=["매년 지정 주기"]))

scored = _claim_row("무엇이든 답합니다.")
score_must_not_claim(scored, _item())          # 라벨 없음
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| 단정 문장 + 「외부 안전성 검증 절차」 | 후보 1문장(둘째 문장은 안 걸림) | 같음 | 통과 |
| **부정문** + 「매년 지정 주기」 | **후보 1문장 — 일부러 안 거른다** | 같음 | 통과 |
| 「국민이 설명을…」 + 「설명 대상을 국민으로」 | 걸린 낱말 `설명 국민` **둘 다** | 같음 | 통과 |
| 금지어가 안 든 답변 | 후보 `[]` · `no_candidate_queries` 에 이름 | 같음 | 통과 |
| 라벨 없음 | 두 칸 `None`(`[]` 아님) | 같음 | 통과 |
| 블록 칸 이름 | `{labeled, entries, candidates, no_candidate_queries}` · float 0개 | 같음 | 통과 |

**낱말 쪼개기(무료·결정적)** — 라벨 문구를 정하기 전에 `_content_tokens()` 에 먹여 봤다.

| 라벨 문구 | 낱말 |
|---|---|
