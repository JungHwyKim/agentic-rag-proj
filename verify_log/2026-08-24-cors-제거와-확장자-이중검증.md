# CORS 제거가 아무것도 안 깨는가, 업로드의 이중 검증이 실제로 어긋나는가

- 검증일: 2026-08-24
- 대상: [task_log/2026-08-24-cors-제거와-확장자-이중검증.md](../task_log/2026-08-24-cors-제거와-확장자-이중검증.md) · 미커밋 (기준 `6e8be1f`)
- 비용: **외부 API 호출 없음.** `detect_format()` 은 매직바이트만 읽고 로더를 안 부른다

## 1. 확인하려 한 것

둘이고 성격이 다르다.

1. **CORS 미들웨어를 걷어내면 무엇이 깨지나** — "규칙이 도는가"에 가깝다. 참조가 정말
   죽어 있었는지를 확인하는 것이라 스위트가 답한다
2. **업로드의 이중 검증(확장자 화이트리스트 + 매직바이트)이 어긋나는가** — `backend.md`
   미결이 *"실제로 어긋나는 사례가 나오는지"* 로 열어둔 것이다. **임계값이 아니라 일치
   여부**라 합성 표본으로 답할 수 있다 — 각 확장자로 올라올 법한 바이트를 만들어
   왕복시키면 된다

## 2. 가상 데이터

무엇을 고립시켰나: **확장자 하나만 바꾼 22개 입력.** 내용은 그 확장자에 맞는 최소 표본이고,
`detect_format()` 이 무엇으로 판정하는지와 그 포맷에 로더가 있는지를 함께 본다.

기대값을 먼저 적었다 — **22종 전부 `OK`**(화이트리스트에 있으면 감지도 되고 로더도 있다).

```python
"""화이트리스트 확장자 22종 각각에, 그 확장자로 올라올 법한 실제 바이트를 만들어
detect_format() 에 태운다. 1차(확장자 화이트리스트)와 2차(매직바이트)가 어긋나는지 잰다."""
from __future__ import annotations

import io
import tempfile
import zipfile
from pathlib import Path

from rag_pipeline.ingestion.loader.detect import detect_format
from rag_pipeline.ingestion.loader.registry import SUPPORTED_EXTENSIONS, _FACTORIES
from rag_pipeline.schemas.document import FileFormat


# ZIP 컨테이너에 판정 마커 하나만 넣은 최소 표본
def _zip(marker: str) -> bytes:
    buf = io.BytesIO()
    with zipfile.ZipFile(buf, "w") as z:
        z.writestr(marker, "<x/>")
    return buf.getvalue()


# 레거시 4종은 표본을 합성할 수 없다. detect 가 olefile 로 **스트림 이름**을 읽는데
# (WordDocument / PowerPoint Document / Workbook / FileHeader) olefile 은 읽기 전용이고
# 저장소에 OLE 픽스처가 없다. 어긋남이 아니라 "못 잼" 으로 가른다
_LEGACY = {".doc", ".ppt", ".xls", ".hwp"}

SAMPLES: dict[str, bytes] = {
    ".pdf": b"%PDF-1.7\n1 0 obj\n<<>>\nendobj\n",
    ".docx": _zip("word/document.xml"),
    ".pptx": _zip("ppt/presentation.xml"),
    ".xlsx": _zip("xl/workbook.xml"),
    ".hwpx": _zip("Contents/content.hpf"),
    ".png": b"\x89PNG\r\n\x1a\n" + b"\x00" * 32,
    ".jpg": b"\xff\xd8\xff\xe0" + b"\x00" * 32,
    ".jpeg": b"\xff\xd8\xff\xe0" + b"\x00" * 32,
    ".gif": b"GIF89a" + b"\x00" * 32,
    ".bmp": b"BM" + b"\x00" * 32,
    ".tif": b"II*\x00" + b"\x00" * 32,
    ".tiff": b"MM\x00*" + b"\x00" * 32,
    ".webp": b"RIFF\x00\x00\x00\x00WEBP" + b"\x00" * 32,
    ".txt": "한글 본문입니다.\n둘째 줄.\n".encode(),
    ".md": "# 제목\n\n본문입니다.\n".encode(),
    ".markdown": "# 제목\n\n본문입니다.\n".encode(),
    ".csv": "이름,값\n가,1\n나,2\n".encode(),
    ".tsv": "이름\t값\n가\t1\n".encode(),
}

rows: list[tuple[str, str, str, str]] = []
tmp = Path(tempfile.mkdtemp())
for ext in sorted(SUPPORTED_EXTENSIONS):
    if ext in _LEGACY:
        rows.append((ext, "-", "있음", "못 잼(OLE 표본 합성 불가)"))
        continue
    data = SAMPLES.get(ext)
    if data is None:
        rows.append((ext, "표본없음", "-", "MISSING-SAMPLE"))
        continue
    p = tmp / f"표본{ext}"
    p.write_bytes(data)
    try:
        fmt = detect_format(p, original_name=p.name)
    except Exception as exc:  # noqa: BLE001 - 측정이라 예외 종류를 그대로 본다
        rows.append((ext, type(exc).__name__, "-", "RAISED"))
        continue
    has_loader = fmt in _FACTORIES
    if fmt is FileFormat.UNKNOWN:
        verdict = "MISMATCH(화이트리스트 통과 → unknown)"
    elif not has_loader:
        verdict = "MISMATCH(로더 없음)"
    else:
        verdict = "OK"
    rows.append((ext, fmt.value, "있음" if has_loader else "없음", verdict))

print(f"{'확장자':<12}{'detect_format':<14}{'로더':<6}판정")
for e, f, l, v in rows:
    print(f"{e:<12}{f:<14}{l:<6}{v}")

bad = [r for r in rows if r[3].startswith("MISMATCH") or r[3] == "RAISED"]
un = [r for r in rows if r[3].startswith("못 잼")]
print()
print(f"총 {len(rows)}종 · 잰 것 {len(rows) - len(un)} · 어긋남 {len(bad)} · 못 잰 것 {len(un)}")
for r in bad:
    print("   ->", r)
```

| 입력(확장자) | 기대 | 실측 `detect_format` | 판정 |
|---|---|---|---|
| `.pdf` | pdf | pdf | OK |
| `.docx` | docx | docx | OK |
| `.pptx` | pptx | pptx | OK |
| `.xlsx` | xlsx | xlsx | OK |
| `.hwpx` | hwpx | hwpx | OK |
| `.png` `.jpg` `.jpeg` `.gif` `.bmp` `.tif` `.tiff` `.webp` | image | image (8/8) | OK |
| `.txt` | text | text | OK |
| `.md` `.markdown` | markdown | markdown (2/2) | OK |
| `.csv` `.tsv` | csv | csv (2/2) | OK |
| `.doc` `.ppt` `.xls` `.hwp` | (doc/ppt/xls/hwp) | **못 잼** | 표본 합성 불가 |

**총 22종 · 잰 것 18 · 어긋남 0 · 못 잰 것 4.** 로더가 아는 13개 포맷이 전부
`SUPPORTED_EXTENSIONS`(22종)에 들어 있다.

### 첫 실행은 어긋남 5건을 냈고 전부 거짓이었다

기대값(22종 OK)을 먼저 적어둔 덕에 불일치가 눈에 띄었고, **원인이 코드가 아니라 표본이었다.**

| 확장자 | 첫 표본 | 왜 틀렸나 |
|---|---|---|
| `.hwpx` | `_zip("Contents/section0.xml")` | 판정 마커는 `Contents/content.hpf` 다 |
| `.doc` `.ppt` `.xls` `.hwp` | OLE 헤더 8바이트 + `\x00` 512 | `detect` 는 `olefile` 로 **스트림 이름**을 읽는다. 스트림이 없으니 전부 `unknown` |

**조잡한 합성 표본은 없는 결함을 있다고 보고한다.** 0단계가 경고하는 "가상 데이터의 자기
확인"은 *통과시키는* 방향인데, 이번은 반대 방향이었고 이쪽이 더 위험하다.
