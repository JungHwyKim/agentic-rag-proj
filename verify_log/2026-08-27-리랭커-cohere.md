## 1. 확인하려 한 것

**"GPU 를 비우면서 품질이 동률인가."** 향상이 아니라 **동률 유지가 합격선**이다
(`plan_log/검색-생성.md` 14회차, 사용자 결정).

임계값을 정하는 검증이 아니라 **짝 비교**다 — 대조군은 `off` 가 아니라 **`local-gpu`** 이고,
같은 60건 · 같은 후보 50개 위에서 순서만 갈아 끼운다.

## 2. 가상 데이터

무엇을 고립시켰나: **응답의 모양 하나.** 실제 호출 없이 폴백 계약이 도는지만 본다.

**가짜를 실제 SDK 모양으로 만드는 것이 이 절의 전부다.** CLAUDE.md 의 LlamaParse 교훈이

list(RerankResponseResultsItem.model_fields)  # → ['document','index','relevance_score']

### 8.5 **여기서 한 번 잘못 짚었다 — 검색이 망가진 줄 알았다**

처음 화면 질의 셋이 **서로 다른 것을 물었는데 전부 EU TRQ 문서**에서 답했다. 검색 붕괴로
보였다. 원인은 제품이 아니라 **내 테스트 하네스**였다 — Git Bash 의 `curl` 이 한국어 본문을
**cp949 로 보냈고** 서버가 UTF-8 로 디코드해 **질의가 깨진 채 도착**했다. 깨진 질의의 임베딩은
아무 데나 붙고, 이 색인은 EU TRQ 가 **181/309 = 59%** 라 그것이 이긴다.

**가른 방법은 응답 HTML 이 되돌려준 질문 문구를 내가 보낸 문자열과 대조한 것 하나다.**

```python
got = re.search(r'bubble user[^>]*>(.*?)</div>', page, re.S)
assert html.unescape(re.sub(r"<[^>]+>", "", got.group(1))).strip() == query
```

**그전에 이미 제품은 무죄라는 증거가 있었다** — 같은 질의를 `retrieve()` 로 직접 부르면
dense 만 / dense+bm25 / dense+bm25+cohere **세 조합 모두** 정답 문서를 상위 5에 냈다.
즉 *스택은 되는데 서버만 안 된다* 는 그림이었고, 그 간극이 곧 전송 계층이었다.

CLAUDE.md 가 `-X utf8` 을 빼면 한국어가 깨진다고 적어 둔 것과 **같은 종류**이고, 이번엔
출력이 아니라 **입력** 쪽에서 났다.
