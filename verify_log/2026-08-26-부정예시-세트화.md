## 2. 가상 데이터

무엇을 고립시켰나: **`answerable` 한 축만** 바꾼 레코드. 나머지 필드는 같게 두고 참/거짓과

```python
# tests/evaluation/test_qa_set.py 의 _negative() 와 같다
from evaluation.qa_set import QAItem, content_hash, validate_items

def negative(**over):
    base = dict(
        query_id="hneg-01",
        query="이 지침의 급식비 단가는 얼마인가요?",
        source_doc="시행령-개정안-안내서",
        gold_spans=[],
        answerable=False,
    )
    base.update(over)
    return QAItem(**base)

print(validate_items([negative()]))                                   # []
print(validate_items([negative(gold_spans=["실제로는 있는 정답"])]))      # 1건
print(validate_items([negative(gold_page={"hwpx": 3, "pdf": 3, "hwpx-가로": 5})]))  # 1건
print(validate_items([negative(answerable=True, gold_spans=[])]))      # 1건 (긍정 회귀)
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| 부정 · `gold_spans=[]` · `gold_page={}` | 문제 0 | 문제 0 | 의도한 변화 |
| 부정 · `gold_spans` 차 있음 | 문제 1 | 문제 1 (`gold_spans 가 차 있다`) | 의도한 변화 |
| 부정 · `gold_page` 차 있음 | 문제 1 | 문제 1 (`gold_page 가 차 있다`) | 의도한 변화 |
| 긍정 · `gold_spans=[]` | 문제 있음 | `gold_spans 가 비었거나…` | 회귀 없음 |
| `answerable` 키 없는 레코드 | `True` | `True` | 의도한 변화 |
| `score_query(..., gold_spans=[])` | `ValueError` | `ValueError: 채점할 수 없다` | 계약 유지 |
