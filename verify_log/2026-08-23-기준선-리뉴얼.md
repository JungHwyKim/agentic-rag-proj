- 검증일: 2026-08-23
- 대상: `task_log/2026-08-23-기준선-리뉴얼.md` (`regression/measure.py` 신설 · `regression/baseline.json` 의 `tests` 블록 재구성)
- 비용: **외부 API 호출 없음.** `detect_regions()` 단독이라 `route_all()` 을 안 타고, `-m integration` 은 안 돌렸다

## 1. 확인하려 한 것

둘이고 성격이 다르다.

1. **임계값이 아니라 불변성** — 측정 설정을 `.env` 에서 명시 dict 로 바꾸면 `documents` 10건의
   값이 움직이는가. 움직이면 새 값이 맞는지부터 가려야 한다
2. **규칙이 도는가** — `fold_by_area()` 가 pytest 수집 출력을 영역별로 옳게 접는가.
   그리고 픽스처가 없을 때 정말 조용히 skip 하는가

앞은 실파일이라야 답이 나오고, 뒤는 가상으로 고립시켜야 경계가 보인다.

## 2. 가상 데이터

무엇을 고립시켰나: **`fold_by_area()` 의 입력 한 축**(노드 id 문자열의 모양)과
**픽스처 유무**. 둘 다 실파일로는 경계를 못 만든다 — 실제 pytest 출력에는 요약 줄이 늘
같은 모양으로 오고, 픽스처는 이 머신에 있어 "없을 때"를 못 만든다.

```python
# tests/regression/test_measure.py 에 그대로 들어간 입력들이다.
from regression import measure

# 축 1 — 노드 id 가 아닌 줄이 섞였을 때 세면 안 된다
measure.fold_by_area([
    "tests/api/test_documents.py::test_upload",
    "",
    "655/662 tests collected (7 deselected) in 1.40s",
    "  warnings summary  ",
    "tests/api/test_documents.py",
])

# 축 2 — 파라미터 대괄호 안의 :: 가 파일 경로를 갈라선 안 된다
measure.fold_by_area(["tests/ingestion/splitter/test_split.py::test_x[a::b]"])

# 축 3 — 윈도우 구분자로 나와도 같은 영역이어야 한다
measure.fold_by_area(["tests\\hooks\\test_a.py::test_x", "tests/hooks/test_b.py::test_y"])

# 축 4 — 픽스처 폴더가 통째로 없는 환경(다른 클론의 기본 상태)
measure.measure_documents(["a.pdf"], fixtures_dir=Path("없는폴더"))
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| 축 1 — 요약·빈 줄·경고 섞인 5줄 | `{"tests/api": 1}` | `{"tests/api": 1}` | 통과 |
| 축 2 — `test_x[a::b]` | `{"tests/ingestion/splitter": 1}` | 같음 | 통과 |
| 축 3 — 역슬래시 1 + 슬래시 1 | `{"tests/hooks": 2}` | 같음 | 통과 |
| 축 4 — 폴더 없음 | `({}, ["a.pdf"])` · 예외 없음 | 같음 | 통과 |
| 종류가 0인 리전 집계 | `{"text": 2, "table": 0, "image": 0}` | 같음 | 통과 |
| `page=None` 인 표 리전 | 집합에서 빠짐 (`{"table": [3]}`) | 같음 | 통과 |

리뉴얼 때 정한 규칙은 *"미커밋 상태는 안 싣는다"* 이고, 그대로 하면 두 영역을 빼야 한다.
대신 **HEAD 를 오염 없이 재는 쪽**을 택했다 — 규칙의 목적은 "커밋에 없는 값을 안 싣는 것"이지
"못 재면 포기하는 것"이 아니다.
