## 1. 확인하려 한 것

둘이다. 성격이 달라 절을 나눠 적는다.

1. **규칙이 도는가** — 검색·생성 배선과 화면이 계약대로 도는가. 특히 `retrieve()` 로 갈라낸
   것이 `run_eval` 의 채점 구조(*"검색은 한 번이고 채점만 여러 번"*)를 안 깼는가
2. **임계값이 얼마인가** — 이번에 정하려던 것이 **아니다.** 프롬프트로만 근거를 묶기로 하고
   점수 임계값은 미룬 상태다. 다만 `dense_score` 가 답변에 실려 나가므로 **관측은 공짜로
   따라온다.** 3절 마지막이 그 첫 관측이고, 표본이 질의 2개라 **판정이 아니라 탐침**이다

## 2. 가상 데이터

무엇을 고립시켰나: **저장소·임베더·LLM 을 전부 가짜로 바꿔** 배선만 남겼다. 세 축이 각각
다른 것을 잡는다 — `top_k` 전달 / 응답 모양 / 템플릿 이스케이프.

```python
# tests/retrieval/test_retrieve_dense.py — 저장소가 받은 top_k 를 기록한다
class FakeStore:
    def __init__(self, results=None):
        self.results = results or []
        self.top_ks: list[int] = []

    def search(self, query_vector, top_k=5):
        self.top_ks.append(top_k)
        return self.results

# tests/generation/test_generate_answer.py — OpenAI 응답 모양을 흉내낸다.
# **문자열로 만들면 안 된다** — 실제는 choices 를 가진 객체다
class FakeResponse:
    def __init__(self, content, *, empty_choices=False):
        if empty_choices:
            self.choices = []
        else:
            message = type("Message", (), {"content": content})()
            self.choices = [type("Choice", (), {"message": message})()]
```

### 3-4. dense 점수 분포 — 미룬 임계값의 첫 관측

3-3 의 두 무리를 한 축에 놓으면 이렇다.

```
근거 있음 :  0.661  0.664  0.673  0.675  0.691
근거 없음 :  0.206  0.214  0.229  0.240  0.253

무리 사이 : 0.253 → 0.661   (2.6배, 사이에 값 0)
무리 안   : 최대 간격 0.016 (있음) / 0.013 (없음)
```

**표본이 질의 2개라 임계값을 정하지 않는다.** 이 저장소가 표시 크기 50pt 를 탐침값으로
박았다가 되돌린 것과 같은 자리이고, 2개는 그때보다도 적다. 다만 *"분포에 틈이 있는가"* 라는
질문에는 **있다** 는 첫 답이 나왔다. 60건 세트로 같은 축을 재면 판정이 가능하다.

**셸에서 `curl --data-urlencode` 로 한국어 질의를 보내지 말 것.** cp949 로 나가 서버가
UTF-8 로 읽으면 질문이 깨진 채 도착하고, **에러 없이 엉뚱한 답이 나온다**(이번에 실제로
겪었고 유료 호출 1회를 버렸다). `httpx`/`requests` 로 보내면 UTF-8 로 나간다.

## 7. 재지 못한 것

- **답변 품질** — 잴 자[尺]가 없다. `evaluation/` 의 60건 세트는 `gold_spans` 가 정답
  *문자열*이라 검색을 재지 생성을 못 잰다. 3-3 의 두 질의는 사람이 눈으로 본 것이고 표본이 2다
- **dense 점수 임계값** — 3-4 참고. 60건 세트로 같은 축을 재면 정해지지만 이번에 안 했다
- **`sources == []` 의 화면** — 코드 경로는 가상으로 검증했지만(2절) **실제로는 발화하지
  않는다.** 컬렉션이 비어 있지 않는 한 dense 가 늘 `top_k` 개를 돌려주므로, 근거 없는 질문
  에서도 소스 태그 5개가 그대로 뜬다(3-3 둘째 줄이 그 상태다). 임계값이 없는 동안은 화면에서
  "근거 있음"과 "근거 없음"이 **답변 문장으로만** 갈린다
- **HWPX 로 같은 화면** — PDF 5개만 색인했다. 두 포맷의 검색 비교는 `평가-세트.md` 몫이다
- **여러 사람이 동시에 쓸 때** — store 싱글턴이 단일 프로세스 전제다. 안 쟀다
- **업로드 실연결** — 목업이라 잴 것이 없다. `index_document()` 가 자기 store 를 여는 문제는
  `plan_log/frontend.md` 미결
