## 2. 가상 데이터

무엇을 고립시켰나: **근거 개수를 2로 고정하고 답변 문자열 한 축만 바꿨다.** 청크 내용은
번호에 아무 영향이 없어(위치가 번호다) 텍스트를 고정했다.

```python
from rag_pipeline.generation import NO_EVIDENCE_ANSWER, check_citations
from rag_pipeline.schemas.retrieval import RetrievedChunk

def chunk(i):
    return RetrievedChunk(
        chunk_id=f"안내서.pdf:{i:04d}", document_id="안내서.pdf",
        text=f"제{i}조 …", metadata={"source_name": "안내서.pdf", "page": i},
        dense_score=0.8,
    )

two = [chunk(1), chunk(2)]
for text in (
    "위약금은 20% 입니다 [1]. 기한은 30일 [2].",
    "위약금은 20% 입니다 [3].",
    "근거 [0] 을 보세요.",
    "[5] 그리고 [3] 또 [5] 입니다.",
    "위약금은 20% 입니다.",
    "[별표 1] 을 보세요 [1].",
    "[별표 1] 을 보세요.",
    NO_EVIDENCE_ANSWER,
    f"  {NO_EVIDENCE_ANSWER}\n",
):
    print(repr(text), "->", check_citations(text, two))
print("근거 0건 ->", check_citations(NO_EVIDENCE_ANSWER, []))
```

| 입력 (근거 2개) | 기대 | 실측 | 판정 |
|---|---|---|---|
| `"… [1]. … [2]."` | `None` | `None` | 의도한 변화 |
| `"… [3]."` | `out_of_range` · `[3]` | `out_of_range` · `[3]` · `source_count=2` | 의도한 변화 |
| `"근거 [0] 을 보세요."` | `out_of_range` · `[0]` | `out_of_range` · `[0]` | 의도한 변화 |
| `"[5] … [3] … [5]"` | `out_of_range` · `[5, 3]` (순서 유지·중복 제거) | `[5, 3]` | 의도한 변화 |
| `"위약금은 20% 입니다."` | `missing` · `numbers == []` | `missing` · `[]` | 의도한 변화 |
| `"[별표 1] 을 보세요 [1]."` | `None` (문서 표기는 인용이 아니다) | `None` | 의도한 변화 |
| `"[별표 1] 을 보세요."` | `missing` (대괄호가 있어도 인용은 0개) | `missing` | 의도한 변화 |
| `NO_EVIDENCE_ANSWER` | `None` | `None` | 의도한 변화 |
| `"  " + NO_EVIDENCE_ANSWER + "\n"` | `None` (strip 후 대조) | `None` | 의도한 변화 |
| 같은 문장 · **근거 0개** | `None` | `None` | 의도한 변화 |

**경계를 셋 다 만들었다** — 범위 바로 아래(`[0]`) · 안(`[1]`,`[2]`) · 바로 위(`[3]`).
`[0]` 은 실파일에 우연히 있을 수가 없어 **가상만 만들 수 있는 입력**이다.

화면 쪽은 앱의 Jinja 환경으로 직접 렌더했다(유료 0).

```python
from backend.app.core.templates import templates
from rag_pipeline.schemas.answer import Answer, CitationTrace
from rag_pipeline.schemas.retrieval import RetrievedChunk

chunk = RetrievedChunk(chunk_id="a:1", document_id="a", text="t", metadata={}, dense_score=0.8)
for trace in (CitationTrace(problem="out_of_range", numbers=[3, 5], source_count=2),
              CitationTrace(problem="missing", numbers=[], source_count=2)):
    answer = Answer(query="q", text="본문", sources=[chunk, chunk], citation=trace)
    html = templates.env.get_template("_answer.html").render(query="q", answer=answer)
    print(html[html.index("citation-row"):].split("</div>", 1)[0])
```

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| `out_of_range` · `[3,5]` · 근거 2 | 근거 수와 번호가 함께 읽힌다 | `근거는 2개인데 [3], [5] 번을 인용했습니다` | 의도한 변화 |
| `missing` | 다른 문장 | `답변에 출처 표시가 없습니다 — …` | 의도한 변화 |
| `citation=None` | 줄 자체가 없다 | `citation-row` 미출력 | 의도한 변화 |

**첫 판은 `[3], [5] 을 인용했습니다` 였고 고쳤다** — 번호가 매번 달라 을/를 을 못 고정한다
(`[3]` 은 «을», `[5]` 는 «를»). 「번」이 받침을 가져 `번을` 이 늘 맞는다.
