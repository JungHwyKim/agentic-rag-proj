# 로컬 임베더(KURE-v1) 배선 검증 — 로컬 의존성 없이 전체가 통과하는가

- 검증일: 2026-08-24
- 대상: [task_log/2026-08-24-로컬임베더-배선.md](../task_log/2026-08-24-로컬임베더-배선.md)
- 비용: **외부 API 호출 없음.** 모델 가중치도 안 받았다 — `_make_model()` 을 전부 모킹했고
  `requirements-local.txt` 는 **아직 설치하지 않았다**(7절)

## 1. 확인하려 한 것

**"규칙이 도는가" 쪽이다. 임계값을 정하는 회차가 아니다.**

가설 셋. (1) 로컬 갈래를 더해도 **기본 설치(`torch` 없음)에서 전체 pytest 가 그대로
통과한다.** (2) 두 프로필이 **서로 다른 캐시·컬렉션 자리**를 본다. (3) `provider` 를
파생에 안 넣기로 한 결정대로 **기본 프로필의 salt 가 한 글자도 안 바뀐다** — 바뀌면 기존
`.cache/embedding` 이 전량 미스가 되어 조용히 재과금된다.

## 2. 가상 데이터

무엇을 고립시켰나: **`embedding_provider` 한 축만** 바꾸고 나머지를 고정했다. 모델 자체는
가짜(`FakeModel`)로 세워 가중치·네트워크를 입력에서 제거했다.

```python
# tests/ingestion/embedding/test_local_embedder.py 의 가짜. encode() 에 넘어온 인자를
# 그대로 보관해 normalize_embeddings 가 실제로 넘어가는지를 본다
class FakeModel:
    def __init__(self, dim: int = 4, vectors: list[list[float]] | None = None) -> None:
        self.dim = dim
        self.vectors = vectors
        self.calls: list[dict] = []
        self.tokenizer = lambda texts, add_special_tokens=True: {
            "input_ids": [[0] * max(len(text), 1) for text in texts]
        }

    def encode(self, batch, **kwargs):
        self.calls.append({"batch": list(batch), **kwargs})
        if self.vectors is not None:
            return self.vectors
        return [[float(i + 1)] * self.dim for i, _ in enumerate(batch)]
```

### 2-1. 프로필별 파생 자리

| 입력 (프로필) | 기대 | 실측 | 판정 |
|---|---|---|---|
| `baseline` salt | `embed:text-embedding-3-small:default` | `embed:text-embedding-3-small:default` | 일치 |
| `baseline` collection | `documents_text-embedding-3-small_default` | `documents_text-embedding-3-small_default` | 일치 |
| `kure-v1` salt | baseline 과 달라야 | `embed:nlpai-lab/KURE-v1:default` | 다름 |
| `kure-v1` collection | baseline 과 달라야 | `documents_nlpai-lab_KURE-v1_default` | 다름 |

**`embedding_dimensions` 를 안 적었는데도 두 자리가 갈렸다** — 모델 이름이 파생에 들어 있기
때문이다. 이것이 `evaluation/README.md` 의 차원 경고 범위를 좁힌 근거다.

### 2-2. provider 만 바꿨을 때 (안 움직여야 한다)

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| `provider` openai→local, salt | 동일 | 동일 | 결정대로 |
| `provider` openai→local, collection | 동일 | 동일 | 결정대로 |

### 2-3. 팩토리 분기와 미설치 경로

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| `get_embedder(provider="openai")` | `OpenAIEmbedder` | `OpenAIEmbedder` | 일치 |
| `get_embedder(provider="local")` | `LocalEmbedder` | `LocalEmbedder` | 일치 |
| `torch` 설치 여부 | absent | **absent** | 기본 설치 불변 |
| `sentence_transformers` 설치 여부 | absent | **absent** | 기본 설치 불변 |
| 미설치 상태로 `embed_documents(["가"])` | 설치 안내 담은 `EmbeddingError` | `로컬 임베딩을 쓰려면 requirements-local.txt 를 설치해야 합니다: uv pip install -r requirements-local.txt` | 일치 |
| `embedding_dimensions=256` 으로 `LocalEmbedder(...)` | `EmbeddingError` | `차원 축소를 지원하지 않습니다` | 일치 |

**미설치 상태에서 `get_embedder()` 자체는 성공한다** — 가중치가 게을러서다. 실제로 벡터를
만들려 할 때 죽는다. 조용히 다른 모델로 떨어지는 경로는 없다.

## 7. 재지 못한 것

**전부 가중치를 받아야 나오는 것들이다.** `requirements-local.txt` 설치(코드 ~140MB) +
KURE-v1 가중치 **2.27GB** 다운로드가 선행하고, `evaluation/README.md` 가 *"사람 승인을 받고
돌린다"* 로 게이트를 걸어 뒀다 — 로컬 갈래라 OpenAI 청구가 0 일 것으로 **예상**되지만
예상과 실측은 다르다.

| 못 잰 것 | 왜 필요한가 |
|---|---|
| **벡터 노름** | `indexing/qdrant_store.py` 가 Dot 을 쓰는 근거가 *"단위 길이"* 실측이다(OpenAI 쪽 0.9998~1.0005). `normalize_embeddings=True` 를 넘긴 것은 확인했지만 **결과 노름은 못 쟀다** — 모델 카드의 `2_Normalize` 를 믿는 것과 재는 것은 다르다 |
| **XLM-R 기준 청크 토큰 분포** | cl100k 기준 최대 1,201토큰이 이 토크나이저로 얼마인지. `max_embedding_tokens_per_doc=200,000` 이 cl100k 기준으로 잡힌 값이라 다시 볼 근거가 여기서 나온다 |
| **CPU 임베딩 시간·메모리** | `embedding_batch_size=100` 을 그대로 뒀다(축을 하나만 바꾸려고). 실제로 도는지 안 재봤다 — 터지면 낮추고 그 값을 다음 회차에 적는다 |
| **검색 수치(`hit@10`·겹침 구간별)** | 이 회차가 만든 프로필의 **목적 자체**다. 60건·20건을 돌려 `evaluation/README.md` 7번 판정표의 어느 칸인지를 읽는다 |
| **리랭커 여지 7건 × 겹침 0 구간의 교차** | `overlap.py` 로 무료지만, **모델 실행과 같은 회차에 재야** *모델이 움직인 것*과 *표적이 원래 좁았던 것*이 안 섞인다 |
