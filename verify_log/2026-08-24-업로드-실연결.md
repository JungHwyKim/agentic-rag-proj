## 1. 확인하려 한 것

**"규칙이 도는가"** 다. 임계값이 없다 — 소유권과 무효화는 값이 아니라 계약이다.

1. **소유권 규칙이 양쪽 끝에서 다 서는가** — 주입한 store 는 안 닫히고, 자기가 연 store 는
   닫히는가. **방향을 거꾸로 잡으면 한쪽이 반드시 죽는다**(주입받은 것을 닫으면 backend 가
   다음 요청에서, 자기가 연 것을 안 닫으면 `run_eval.py` 가 색인 직후 검색하다가)
2. **라우트가 캐시 둘을 다르게 다루는가** — BM25 는 되돌리고 답변 캐시는 그대로 두는가

## 2. 가상 데이터

무엇을 고립시켰나: **`store` 인자 하나.** 같은 파일·같은 설정으로 넘길 때와 안 넘길 때만
가른다. 입력은 `tests/conftest.py` 의 `docx_file` 픽스처를 그대로 쓴다(새 생성 방식을
만들지 않았다). 임베딩은 `fake_embedding_api` 가 `_make_client()` 를 갈아끼운다.

기대값을 먼저 적었다.

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|
| `index_document(..., store=열어둔 store)` 뒤 그 store 로 `count()` | 살아 있어야 함 (안 닫힘) | 살아 있음 · `count() == chunk_count` | OK |
| 같은 store 로 연달아 두 번 색인 | 둘 다 성공 · 청크 수 그대로(재색인) | `second.chunk_count == first.chunk_count` · `store.count()` 동일 | OK |
| `store=` 없이 색인한 뒤 `get_store()` 로 다시 열기 | 열려야 함 (닫혔음) | 열림 · `count() > 0` | OK |

세 번째가 **자기가 연 것을 여전히 닫는지**를 잡는다. 이것이 `run_eval.py` 가 기대는 자리다.

라우트 쪽은 `index_document()` 를 갈아끼워 **계약만** 본다(색인의 의미는 위 3종이 덮는다).

| 입력 | 기대 | 실측 | 판정 |
|---|---|---|---|

| 같은 호출의 `index_document` 인자 | `store is app.state.store` · `config is app.state.ingest_config` | 그대로 | OK |
| 호출 뒤 `app.state.store.closed` | `False` (수명은 lifespan 이 쥔다) | `False` | OK |
| 호출 뒤 `app.state.bm25` | `None` (스냅샷이라 낡는다) | `None` | OK |
| 호출 뒤 `app.state.answer_cache` | **같은 객체** (건드리면 안 된다) | 같은 객체 | OK |
| `.exe` 업로드 | 415 · `index_document` 미호출 | 그대로 | OK |
| 색인이 예외를 낼 때 `app.state.bm25` | 그대로 (저장소가 안 바뀜) | 그대로 | OK |

### 실패 경로 테스트의 예외 타입을 바꿨다

처음에 실패 신호로 `RuntimeError` 를 썼다. **그것이 qdrant 배타 잠금이 던지는 바로 그
타입이다**(`Storage folder ... is already accessed by another instance`). 삼키고 뒤 상태만
단언하면 **주입이 동작해서 통과한 것**과 **잠금으로 죽었는데 단언이 우연히 맞는 것**이
구분되지 않는다.

ruff 가 `SIM105`(try-except-pass)로 걸었지만 **권고대로 `contextlib.suppress` 로 바꿨으면
린트만 조용해지고 그 구분 문제는 그대로였다.** 전용 예외 + `pytest.raises` 로 고쳤다 —
이제 잠금 오류는 안 잡히고 그대로 터진다.

```python
class _IndexingBoom(Exception):
    pass


def test_failed_index_keeps_bm25(mocker):
    mocker.patch(
        "backend.app.api.routes.documents.index_document",
        side_effect=_IndexingBoom("색인 실패"),
    )
    index = object()
    client, app = _client(bm25=index)

    with pytest.raises(_IndexingBoom):
        client.post("/api/v1/documents/index", files=_files())

    assert app.state.bm25 is index
```
