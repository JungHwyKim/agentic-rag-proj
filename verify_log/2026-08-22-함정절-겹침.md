# 함정 절 26항목이 정말 저장소 어디에도 없는가 — 6회차 수치의 재측정

- 검증일: 2026-08-22
- 대상: `plan_log/문서-최신성.md` 6회차가 미결 근거로 쓴 "26항목 중 6개는 어디에도 없다"
- 비용: 외부 API 호출 없음. `-m integration` 안 돌림

## 1. 확인하려 한 것

6회차는 단계별 절을 걷어내면서 함정 절은 **"6개가 이 저장소 어디에도 없어 같은 논리가 안
먹힌다"** 는 이유로 남겼다. 그런데 같은 회차의 검증 기록 7절이
*"1차로 재본 키워드 겹침률은 오탐 4건 때문에 신뢰할 수 없어 수치를 남기지 않는다"* 고
적었다. **그 신뢰할 수 없는 자로 잰 값이 결론의 근거가 돼 있다.** 다시 잰다.

가설: 단계별 절에서 그랬듯 **오탐일 것이다.** 확인하려는 것은 임계값이 아니라 집합 포함
관계라 실파일 픽스처가 필요 없다 — 입력은 저장소 자신이다.

## 2. 가상 데이터

**없음.** 직전 회차와 같은 이유다. 합성 문서로 만들 축이 없다 — 파싱 규칙이 아니라 문장의
존재 여부를 본다.

## 3. 실제 데이터

### 코퍼스 — 여기가 1차 측정의 세 번째 오류였다

1차는 `.py` 와 `.md` 만 읽었다. **설정은 `.env.example` 에 산다.** 그래서 Tesseract 항목이
통째로 빠졌다. 이번에는 확장자 제한을 없애고 구역을 다섯으로 갈랐다.

| 구역 | 대상 |
|---|---|
| src | `rag_pipeline/` · `backend/` |
| conf | `.env.example` · `pyproject.toml` |
| tests | `tests/` |
| review | `.claude/skills/` |
| logs | `task_log/` · `verify_log/` · `plan_log/` |

### 결과 — 함정 26항목을 주장 29개로 풀어 대조

| 판정 | 건수 |
|---|---:|
| 있음 (한 구역 이상) | 28 |
| 기록(logs)에만 | 1 |
| **어디에도 없음** | **0** |

기록에만 있는 1건은 **"같은 문서라도 포맷이 청크 수를 가른다"**(HWPX 45청크 vs PDF 104청크)
이다. 이것은 계약이 아니라 **관측**이고, 그 항목의 결론 자체가 *"어느 쪽이 검색에 유리한지는
아직 못 잰다 — 정답 질의 세트가 없다"* 라 코드에 반영할 것이 없다.

### 1차가 "6개 없음"이라고 한 것들의 실제 위치

| 1차 판정 | 실제 |
|---|---|
| `\n` 은 지우면 안 된다 (560개) | src · tests · review · logs — 네 구역 전부 |
| Cf 감수 사항 (ZWJ) | `cleaner/characters.py` · `references/cleaner.md` |
| 600px 임계값 | src · tests · review · logs 전부 |
| Tesseract / `TESSERACT_CMD` | `config.py:tesseract_cmd` · `.env.example` |
| legacy 포맷 415 | src · tests · review · logs 전부 |
| zip bomb | `loader/detect.py` · `references/loader.md` |

### 오탐이 난 세 가지 경로

| 원인 | 예 |
|---|---|
| needle 이 코드 표기와 다름 | `PIL.Image.format` 으로 찾았는데 코드는 `image.format` |
| needle 이 고쳐지기 전 수치 | `4개 표 리전` 으로 찾았는데 되붙이기 뒤 문서에는 `5개` |
| **코퍼스 확장자 제한** | `.py`/`.md` 만 봐서 `.env.example` 을 놓침 |

### 분산도 — 이번 회차가 새로 얻은 것

함정 항목이 백틱으로 지목하는 소스 파일을 셌다.

| 항목 | 값 |
|---|---:|
| 함정 항목 수 | 26 |
| **어느 파일도 안 가리키는 항목** | **18 (69%)** |
| 파일을 가리키는 항목 | 8 |
| 언급된 서로 다른 파일 수 | 6 (`pdf.py` 에 4개 집중) |

`한국어 청크는 문자 ≈ 토큰이다` 는 splitter 것도 embedding 것도 아니고,
`LlamaParse 응답의 markdown 은 문자열이 아니다` 는 SDK 사실이다. **단계별 절이 가졌던
"그 단계 패키지"라는 홈이 함정에는 대부분 없다.**

## 6. 재현

```powershell
.\.venv\Scripts\python.exe -X utf8 <재측정 스크립트>
```

스크립트는 스크래치패드에 두고 저장소에 남기지 않는다. 뼈대는 직전 회차
(`2026-08-22-claude-md-다이어트.md` 6절)와 같고 **두 곳만 다르다** — 코퍼스에서 확장자
제한을 없앨 것, 그리고 구역을 `src`/`conf`/`tests`/`review`/`logs` 다섯으로 가를 것.
`logs` 를 따로 두지 않으면 "기록에만 있음"을 "있음"과 못 가른다.
