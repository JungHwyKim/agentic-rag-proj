# 재색인 라우트의 계약을 잠근다 — 무엇이 `index_document()` 로 넘어가는가

- 검증일: 2026-08-26
- 대상: `task_log/2026-08-26-재색인-API.md` (미커밋 · `POST /documents/{document_id}/reindex`)
- 비용: **외부 API 호출 없음.** `-m integration` 7건은 기본 설정대로 deselect 됐고,
  `index_document()` 는 전 테스트에서 갈아끼워 임베딩·qdrant·LLM 어느 것도 안 탄다

## 1. 확인하려 한 것

**"규칙이 도는가" 쪽이다.** 이번 변경에는 정할 임계값이 없다 — 라우트가 무엇을 읽고 무엇을
넘기고 무엇을 뒤처리하는가가 전부다. 그중 **에러 없이 틀릴 수 있는 둘**을 겨냥했다.

1. `original_name` 에 디스크 이름(`안내서__a3f9c2.pdf`)이 아니라 문서 키(`안내서.pdf`)가
   넘어가는가 — 틀리면 `document_id` 가 새로 생겨 delete 가 옛 청크를 못 찾고 같은 문서가
   두 벌이 된다
2. `store` 가 주입되는가 — 안 넘기면 `index_document()` 가 자기 클라이언트를 열어 같은
   uvicorn 안에서 배타 잠금과 부딪힌다. **테스트 없이는 운영에서만 드러난다**

## 2. 가상 데이터

무엇을 고립시켰나: **원본 파일의 존재 여부 한 축**이다. 파일 내용은 라우트 계약과 무관하도록
`index_document()` 를 갈아끼웠고, 남긴 축은 *"보관함에 그 이름의 파일이 있는가"* 뿐이다.

저장 이름은 손으로 적지 않고 라우트와 **같은 함수**로 계산한다 — 손으로 적으면 규칙이
바뀌었을 때 테스트만 통과한다.

```python
from backend.app.api.routes.documents import _stored_name

def _place_original(originals_dir, document_id):
    originals_dir.mkdir(parents=True, exist_ok=True)
    path = originals_dir / _stored_name(document_id)
    path.write_bytes(b"PK\x03\x04 not really a document")
    return path

# app.state 는 가짜를 직접 꽂고 lifespan 은 일부러 안 돌린다 —
# 진짜 저장소를 열면 개발자의 실제 .qdrant 를 건드린다
app = create_app()
app.state.ingest_config = IngestConfig()
app.state.store = FakeStore()      # list_documents() 만 있다
app.state.bm25 = object()
app.state.answer_cache = FakeCache()  # clear() 횟수만 센다
```

### 배선이 실제로 붙었는지 — 테스트 밖에서 한 번 더

라우터 등록은 `app.routes` 로 못 본다. 이 FastAPI 버전이 `include_router` 를
`_IncludedRouter` 로 감싸 `path` 가 `None` 이다(실제로 8개 중 3개가 그랬다). OpenAPI 로 본다.

```
['get']    /api/v1/documents
['post']   /api/v1/documents/index
['post']   /api/v1/documents/upload
['delete'] /api/v1/documents/{document_id}
['get']    /api/v1/documents/{document_id}/original
['post']   /api/v1/documents/{document_id}/reindex   <- 이번에 생긴 것
```

`hx-disabled-elt` 가 벤더링한 htmx 에 실재하는지도 봤다 — `backend/app/static/htmx.min.js`
에 1건. 없으면 **속성이 조용히 죽어** 연타가 두 요청이 된다.

## 7. 재지 못한 것

- **화면 E2E 를 안 돌렸다.** uvicorn 을 띄우면 `.qdrant` 배타 잠금을 잡아 다른 세션과
  부딪히고, 진행 표시·`hx-confirm`·버튼 노출은 브라우저에서만 확인된다. 사람이 눌러야 한다
- **진짜 재색인의 결과를 안 쟀다** — `index_document()` 를 갈아끼웠으므로 *"보관된 원본으로
  다시 색인하면 청크 수가 그대로인가"* 는 이 기록이 답하지 않는다. 답하려면 실제 `.qdrant`
  와 실파일이 필요하고, 그것은 `regression-test` 의 자[尺]다
- **그림자 재색인의 과금 크기를 안 쟀다.** 그림자가 켜진 환경이 아니라 호출 인자만 봤다
