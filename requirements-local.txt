# 로컬 임베딩 갈래. **기본 설치에 안 들어간다** — `requirements.txt` 를 그대로 두고 이 파일만
# 따로 받는다.
#
#   uv pip install -r requirements-local.txt
#
# ## 왜 본체가 아닌가
#
# 로컬 프로필(`EMBEDDING_PROVIDER=local`)을 안 쓰는 사람에게 코드 ~140MB 와 **가중치 2.27GB**
# 가 간다. 그런데 더 큰 이유는 부수 효과다 — **기본 pytest 환경에 `torch` 가 아예 없으면
# "모델 가중치를 조용히 내려받는 경로" 가 구조적으로 없다.** `tests/conftest.py` 의
# `offline_config` 가 provider 를 못 박는 것과 두 겹이 된다. 지금까지의 방어는 "키를 지운다"
# 였는데 **로컬 모델은 키가 없어도 돌기 때문에** 그 방어가 여기서는 안 통한다.
#
# ## 왜 CPU 인가
#
# Windows/PyPI 의 `torch` 휠이 CPU 빌드다. GPU 로 가려면 PyPI 밖 `--index-url` 이 필요한데
# **일부러 안 간다** — 재현성이다. cu128 을 깐 머신에서만 GPU 로 가면 같은 명령이 다른 벡터를
# 내고 "baseline 은 재현될 때만 기준선" 이 무너진다(`evaluation/config.py` 가 `.env` 를 막은
# 것과 같은 잣대). 그래서 `LocalEmbedder` 가 device 를 `cpu` 로 못 박고 설정으로 열지 않는다.
