## 2. 설계 결정

### 절단면을 "삼중으로 적힌 것"으로 잡았다 — 크기가 아니라 중복이 기준

CLAUDE.md 는 15,910토큰이었고 제일 큰 절은 **함정 절(6,189)** 이지 단계별 절(3,821)이
아니었다. 크기로 골랐으면 함정 절을 잘랐을 것이다. 그런데 1회차가 이미 실측으로
*"안 낡은 쪽은 전부 함정"* 이라고 답해뒀고, 이번에 세어보니 함정 26항목 중 **6개는 이 저장소 어디에도 없다**
(`\n` 은 지우면 안 된다 · Cf 감수 사항 · 600px 임계값 · Tesseract · legacy 포맷 · zip bomb).
재취득 비용이 큰 실측을 안 읽히는 자리로 옮기는 셈이 된다.

> **정정 (7회차, 같은 날).** 위 "6개는 어디에도 없다"는 **틀렸다.** 이 세션이 단계별 절에서
> 폐기한 키워드 겹침률로 잰 값을 함정 절에는 그대로 쓴 결과다. 문장 조각으로 다시 재니
> **어디에도 없는 것은 0건**(주장 29개 중 기록에만 있는 것 1건)이다 —
> [verify_log/2026-08-22-함정절-겹침.md](../verify_log/2026-08-22-함정절-겹침.md).
> **결론(함정 절 유지)은 그대로지만 근거가 바뀌었다: 중복이 아니라 옮길 홈이 없다** —
> 26항목 중 18개(69%)가 어느 파일도 안 가리킨다.

반면 단계별 절은 모듈 docstring · 하위 모듈 docstring · `references/*.md` 에 **삼중**이었다.
35개 문구 대조에서 **미검출 0건**이다. 잃는 것 없이 자를 수 있는 유일한 면이었다.

버린 것:
- **함정 절까지 함께** — 위 근거로 기각. 미결로 열어 한 사이클 지켜본다
- **`@import` 로 파일만 분할** — Claude Code 는 `@path` 를 CLAUDE.md 와 **함께 컨텍스트에
  펼친다.** 토큰이 안 줄고 중복도 그대로라 목적을 하나도 달성 못 한다

### 포인터를 `references/*.md` 가 아니라 모듈 docstring 으로 향하게 했다

산문은 `references/` 쪽이 훨씬 두껍다(`cleaner.md` 12,032B). 그런데 저건
`rag-code-review` 의 **리뷰 기준**이고 라우팅 표가 연다. CLAUDE.md 가 저기를 가리키면
설계 문서와 리뷰 기준의 용도가 섞인다. docstring 은 **그 파일을 고치는 사람이 반드시 보는
자리**라 낡을 확률도 제일 낮다.

### "되돌리면 안 되는 것" 한 줄을 지어내지 않았다

표에 단계당 한 줄만 들어가는데, 각 단계의 Critical 은 6~8개다. 무엇을 남길지 내 판단으로
고르는 대신 각 `references/<stage>.md` 의 `## 2. 되돌리면 깨지는 것` **첫 항목**을 옮겼다.
이미 *에러 없이 조용히 틀린 결과를 낳는* 순서로 골라져 있던 목록이다.

그래서 splitter 칸이 처음 후보였던 "표는 조각마다 헤더 반복" 대신 **"제목 머리를 예산에서
미리 뺀다"** 가 됐고, embedding 칸이 "빈 결과 아니라 예외" 대신 **`len(반환)==len(입력)`**
이 됐다. 뒤엣것이 앞엣것을 포함하면서 **자리 밀림**까지 덮는다.

### 색인 절을 만든 이유 — 포인터가 안 닿았다

*"자세히는 `__init__.py` docstring"* 이라고만 쓰면 **30건 중 12건이 하위 모듈에 있어
따라가도 안 나온다**(`oversized.py` · `qdrant_store.py` · `records.py` · `schemas/vector.py` 등).
새 발명은 아니다 — `cleaner/__init__.py` 가 *"문자 수준(characters, whitespace) / 문서
수준(headers)"* 로 이미 같은 일을 하고 있었고, 그 모양을 넷으로 맞춘 것이다.

버린 것: **하위 모듈 산문을 `__init__.py` 로 모으기** — 포인터는 정확해지지만
**새 중복을 만든다.** 중복 제거가 목적인 작업과 정반대 방향이다.

## 4. 실패 분석

### 첫 측정이 "옮길 것 4건"이라고 말했는데 전부 오탐이었다

처음에 각 주장에서 숫자·백틱 식별자·6자 이상 한글 덩어리를 키워드로 뽑아 겹침률을 쟀다.
"어디에도 없음"이 4건 나왔다 — 겹침은 쪼갠 구간에만 / 원소별 비교 금지 / Dot 고정 /
크기 하한 없음. **네 건 전부 이미 있었다.** 문구가 달랐을 뿐이다.

| CLAUDE.md | 실제 위치 |
|---|---|
| 겹침은 **상한 초과로 쪼갠 구간에만** 준다 | `oversized.py` — 겹침(overlap)은 **여기서만** 준다 |
| 거리 척도는 Dot 고정이고 설정이 아니다 | `qdrant_store.py` — 왜 거리 척도가 설정이 아닌가 / **Dot 으로 고정한다** |

`plan-log` 2단계의 **"자[尺]를 먼저 의심하라"** 와 같은 종류다. 겹침률은 실측처럼 보이는데
**같은 뜻의 다른 문구를 구조적으로 못 본다.** 그대로 믿었으면 이미 있는 문장 4개를 다시
써넣어 새 중복을 만들었을 것이다. 판정을 문장 조각 매칭으로 바꿔 최종 35/35 를 얻었다.

막은 방법: **회귀 테스트로 못 막는다.** 일회성 측정 도구라 저장소에 안 남는다. 대신
`verify_log/` 6절에 "셋째 칸이 키워드가 아니라 문장 조각이어야 한다"를 스크립트 뼈대와
함께 남겼다.

### 힙독의 백슬래시가 한 번 벗겨져 제어문자가 파일에 박혔다

cleaner docstring 에 `\n` · `\t` · `\r` 을 쓰려고 Python 힙독에 이스케이프해 넣었는데
**실제 개행·탭·캐리지 리턴이 파일에 들어갔다.** 하필 그 문단이 *"개행은 남기고 캐리지
리턴은 개행으로 바꾼다"* 를 설명하는 자리라 눈에 안 띄었으면 그대로 남았을 것이다.
`od -c` 로 확인하고, **백슬래시를 아예 안 쓰는 문장**("개행과 탭은 남기고 캐리지 리턴은
개행으로 바꾼다")으로 다시 썼다.

같은 함정이 커버리지 스크립트에서 한 번 더 났고(`'\'` → `''` 로 SyntaxError),
`chr(92)` 로 우회했다.

막은 방법: 이것도 회귀 테스트로는 못 막는다 — 파일 내용이 아니라 **작성 경로**의 문제다.
docstring 이 파싱되는지는 `import` 로 확인했다.

### 계획서에 적은 pytest 기대값이 틀렸다

"337개 전부 통과여야 한다"고 썼는데 실제는 **540**이다. CLAUDE.md 예시 문구에서 본 옛
수치를 그대로 옮긴 것이다. `verify-log` 2단계가 *"기억이나 대화 위쪽의 값을 옮겨 적지
않는다"* 고 경고하는 바로 그 실수다. 판정에는 영향이 없었다(전후 비교로 봤다).
